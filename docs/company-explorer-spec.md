# ロゴで探せる企業探索

実装日：2026-10-17。本番反映・GA4受信・実ブラウザ表示は未確認。

## 目的と入口

業界地図の領域別の見やすさを企業一覧へ取り込み、ロゴ・企業名・短い役割から会社を探す。`/industry-map`は代表31社の分業構造、`/companies`は掲載37社の検索を担う。両URL、タイトル・説明、自己参照canonical、sitemap、企業一覧の検索条件付きURLのnoindexを維持する。URL統合・転送は行わない。

工場新設記事・国内拠点マップ、ログイン、保存、外部API、AI、企業データの拡張は対象外。

## 表示と操作

- 共通カードは白いロゴ枠、常時表示の企業名、既存の事業モデルを表示。ロゴ・社名のボタンで概要を開き、企業詳細のある会社には常設の通常リンクも用意する。
- 概要はnative dialog。PCは中央、720px以下は下部。閉じる、Escape、実際の枠外クリックで閉じ、表示中の起点へフォーカスを戻す。起点がなくなった場合は検索欄へ戻す。内部の余白クリックでは閉じない。
- 概要に説明、製品・職種、国内拠点・キャリア準備への既存導線、出典と元データの更新日を出す。地図専用の簡易紹介7社には公式URLを使い、架空の企業詳細URLを作らない。
- 共通操作はキーワード、本社地域（全て・日本・海外）、国内拠点情報あり、条件クリア。一覧は既存6セグメント、地図は職種との接点表示を追加する。
- キーワードはNFKC・英字大小を正規化。企業名、和名、説明、事業、国、製品、職種を対象に、空白区切りの全語を含む会社を抽出する。
- 会社ごとの主領域は1つとし件数を重複させない。0件の領域を省略し、解除で固定順へ戻す。地図の通常表示は固定ゾーン、検索中は一致領域を詰めて表示。
- 地図の8領域は従来の淡い背景色・枠色・見出し線で区別し、領域名も常時表示する。企業カード・ロゴ枠は白地を維持。企業一覧の領域背景は淡いグレーとする。
- 地図検索0件でも掲載37社に一致する場合は、地図未収録かつ同じ地域・拠点条件に合う企業を最大3社、別枠で案内する。
- `/companies?query=…`、`#company-search`、`#industry-zone-*`、`#company=…`、`#supply-chain-*`を維持。共有企業指定は許可された31社のみ復元し絞り込みを解除。未知・重複指定は案内を出す。
- 企業名・企業詳細リンク・簡易紹介の公式リンクを初期HTMLに含め、JavaScriptなしでも企業研究へ進める。

## 実装とロゴ

Server ComponentのIndustryAtlas・FilterableCompaniesが静的データを整え、共通Client ComponentのCompanyExplorerへ渡す。CompanyExplorerItemが既存企業と簡易紹介を区別し、主領域・既存セグメント・出典・更新日・各導線の有無を持つ。表示モードはatlas/directory、計測元は明示したパス。元のCompany型・セグメント分類を変更しない。

地図外13社の主領域は、Skyworks・Broadcom・Marvell・Qorvoをファブレス、Infineon・ST・NXP・onsemi・Analog Devices・TIをIDM、日立ハイテクを検査・計測、Nikon・Canonを製造装置とする。未分類の新規企業は組み立て時にエラーとし、黙って落とさない。

CompanyCardLogoにcompactサイズを追加し、既定サイズは維持。ロゴ枠は最大112×40px、スマホ96×32px。スマホは2列、320px幅からはみ出さず主要操作44px以上。ロゴなし・読み込み失敗は文字へ戻す。画像は装飾扱いとし企業名を重複して読み上げない。

信越化学・東京応化工業の保存済みPNGを探索台帳へ登録。追加15社は提供元ページの社名・銘柄コード・原画像を照合してローカル保存し、取得日・ページ・画像URLを台帳へ記録。地図31社、掲載37社中36社がロゴ対応。日立ハイテクは対応画像を取得できず文字表示を維持し、親会社ロゴを代用しない。ロゴ取得日で企業情報の更新日を変更しない。

両ページに画像提供元を表示する。閲覧時の外部画像取得・ロゴ生成・画像変形を行わない。出典と利用条件は`public/images/company-logos/README.md`。

## 計測と評価

ui_versionはcompany-explorer-v1、source_pageは各ページのパス。初期表示・再描画だけで操作イベントを送らず、検索語を送信・保存しない。計測利用不可でも検索・概要を利用できる。

地図のindustry_map_node_open・detail_view・content_click・search_result・filter_use・career_layer_change・category_clickを維持。共有detail_viewは同一マウント・企業IDで重複抑止。検索は同じ正規化語のEnterとblurを二重計上しない。ノード開閉と詳細閲覧を合算して人数としない。

一覧のcompanies_filter_useは既存キーワード・分野・地域を維持し、拠点条件・クリアを追加。companies_company_openは企業研究先へのリンク操作とし、destination・placementを付ける。概要は新しいcompanies_summary_openで計測し、既存の詳細遷移に混ぜない。

本番反映日と通常利用の受信を確認後、14日・28日でURL・検索語ごとのクリック、概要表示、企業詳細への同一セッション内の遷移を観察。少数なら延長し、イベント件数の単純比を転換率としない。アクセス数値は非公開記録へ保持。GA4設定変更・自動取得・通知は今回行わず、URL統合は別判断とする。
