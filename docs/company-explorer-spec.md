# 業界地図・企業一覧の統合探索

統合・俯瞰表示の実装日：2026-10-17。本番反映・HTTP転送・GA4受信・実ブラウザ表示は未確認。

## 目的と入口

`/industry-map`を、業界構造を理解して企業を探す1つの入口へ統合する。見出し・メニュー・トップの名称は「業界地図・企業一覧」。初期表示は8領域・全44社で、企業詳細のある37社と出典付き簡易紹介7社を区別する。既存の淡い領域別背景色・枠色・見出し線と、白いロゴカードを維持する。

構成は短い説明・掲載範囲、検索・開閉式の絞り込み、1行の一般的な分業の流れ、8領域44社の地図、全44社の詳細・公式リンクと領域説明の開閉欄、日本企業一覧、工程解説・関連情報。企業一覧側の日本企業の社名・主力製品・詳細リンクを移し、重複する分類説明・相互案内を整理する。日本企業一覧は企業詳細のある日本本社企業を対象とし、企業網羅性を主張しない。

工場新設・国内拠点マップは機能変更対象外。新規企業詳細、ログイン、保存、外部API・DB、AI、画像取得・生成は追加しない。関連ページから旧一覧へのリンク先更新は行う。

## データ・操作・表示

- Server ComponentのIndustryAtlasが既存37社・国内拠点・キャリア情報と簡易紹介7社をCompanyExplorerItemに整え、CompanyExplorerへ渡す。別の一覧モード・FilterableCompaniesは廃止する。
- 主領域は1社1つ。既存31社の各領域内の順序を保ち、追加13社を元の企業データ順で各領域の末尾に加える。既存のCompany型と6セグメントは変更しない。
- 追加13社の主領域はSkyworks・Broadcom・Marvell・Qorvoがファブレス、Infineon・ST・NXP・onsemi・Analog Devices・TIがIDM、日立ハイテクが検査・計測、Nikon・Canonが製造装置。組み立て時に未分類があればエラーとし、黙って落とさない。
- 検索欄・結果件数・条件クリアは常に操作できる位置に置く。日本／海外、国内拠点情報あり、6セグメント、職種表示は初期状態で閉じたnative detailsの「絞り込み」にまとめる。閉じた後も件数・適用条件数を表示し、クリア操作を隠さない。6セグメントの対象は既存分類のある詳細37社と注記し、簡易紹介に推測の分類を付けない。
- 検索はNFKC・英字大小を正規化し、企業名・和名・説明・事業・国・製品・職種から空白区切りの全語一致で抽出する。複数条件を組み合わせ、0件の領域を省略し、解除で44社・元の順序へ戻す。別の企業一覧への0件案内は不要。
- 地図カードはロゴと社名だけを主役にし、説明・詳細リンク行は置かない。簡易紹介のラベルは別行の隅に確保しロゴ・社名へ重ねず、概要ボタンの読み上げにも含める。概要内と地図直下の閉じたnative detailsに、37詳細・7公式リンクを保持する。リンク一覧は検索と独立して全44社を領域別に掲載し、JavaScriptなしでも開閉・遷移できる。架空の詳細URLを作らない。
- 概要はPC中央・720px以下で下部のnative dialog。製品・職種、既存の拠点／キャリア準備リンク、出典・確認日・更新日を表示。閉じる・Escape・枠外クリックで閉じ、表示中の起点へフォーカス復帰。起点が消えた場合は検索欄へ戻す。
- 地図内はoverviewロゴ最大72×24px、社名13px以上の全文折り返し、主要操作44px以上。1023px以下は領域を縦に、企業を2列に並べ、320px幅から横はみ出しを避ける。縦横比・ブランド色、他ページのdefault／compactサイズを維持し、画像なし・読み込み失敗は文字へ戻す。
- ロゴは既存ローカル台帳の43社が対応。日立ハイテクは文字表示を維持し、親会社ロゴを代用しない。閲覧時の外部画像取得は行わない。取得元・条件は`public/images/company-logos/README.md`。

## 俯瞰レイアウト

PCは12列の2段固定配置。上段はEDA・IP 2列、ファブレス4列、ファウンドリ2列、OSAT 2列、検査・計測2列。下段は材料2列、IDM 6列、製造装置4列。領域内の企業列数は上段1／3／1／1／1、下段1／4／3。領域の表示順・DOM順を揃え、領域内は元の企業順を維持する。8色は従来の配色を使う。検索中は一致領域を詰め、解除で固定配置へ戻す。

ヘッダー直下の導入を短くし、重複見出し・説明・領域リンク集・大きな誘導ボタンを外す。既存の検索用見出し・アンカーは読み上げ可能な形で保持する。「設計 → 製造 → 後工程」と、材料・装置・検査は複数工程を支えるという注記だけを地図前に置き、個社間の取引や資本関係は示さない。領域の長い説明と関連リンクは地図下の閉じた開閉欄へ移す。

1440×900pxの標準文字サイズで、ヘッダー・導入・検索・全44社の地図を最初の画面に収めることが目標。1280×800pxは文字と操作サイズを優先し縦スクロールを許容。地図の固定高さ・縮小変形・社名の切り捨てを行わない。絞り込み・職種を展開した場合や検索中は、初期表示の高さに拘束しない。一画面への収まりは実ブラウザ検証まで未確認とする。

## URL移行・SEO

- Next設定の完全一致`/companies`→`/industry-map`をpermanentで設定（308）。旧一覧のServer ComponentにもpermanentRedirectを残す。クエリの空値・複数値・他パラメーターを引き継ぐ。詳細以下へのワイルドカード転送はしない。
- `/companies/[slug]`、`/companies/global-japan`、比較ページは従来URLを維持。サイト内の一覧トップへのリンクは記事本文・構造化データも含め統合先へ直接更新し、メニュー・トップの重複入口を除く。
- `?query=…`の先頭値を初期検索に使う。同ページ内でquery付きリンクへ移動した場合も、新しいqueryで探索部品を再マウントする。
- 旧`#company-search`・`#company-search-title`・`#japanese-companies`・日本企業の見出し・`#companies-role-title`・`#companies-taxonomy-title`・`#companies-adjacent-title`・`#directory-zone-*`を統合先に維持。地図の`#industry-atlas-title`・`#industry-zone-*`・`#supply-chain-*`も維持する。HTTPの転送先にはfragmentを付けず、旧fragmentを統合先で解決する。
- `#company=…`は全44社を許可。指定企業の復元時は絞り込みを解除し概要を開く。未知・重複指定は案内し、架空の企業を表示しない。
- タイトルは「半導体業界地図・日本と世界のメーカー一覧【2026年版】」。説明と本文に8領域・44社・詳細37社と簡易紹介7社の範囲を示す。
- canonicalは`/industry-map`。基本URLはindex、query指定時は空文字・0件もnoindex, follow。sitemapから旧一覧トップだけを外し、企業詳細・外資系企業の日本の仕事を残す。
- BreadcrumbListは統合先、ItemListは44社と実在する詳細URL／公式URLに対応させる。会社名・リンクと日本企業一覧を初期HTMLに含め、JavaScriptなしでも企業研究へ進める。

## 計測・評価・公開

全44社の探索は既存industry_map_node_open・detail_view・content_click・search_result・filter_use・career_layer_change・category_clickを使う。source_pageは`/industry-map`、ui_versionは`overview-atlas-v3`。全社リンク一覧のクリックはcontent_clickのlink_location=company_link_indexで区別し、概要内はdetail_panelを維持する。旧companiesイベントを重ねて送らない。初期表示・再描画で操作イベントを発火せず、共有復元は企業IDにつきマウント中1回、検索は同じ正規化語のEnter/blurを重複させない。自由入力の検索語は送信・保存せず、計測失敗でUIを止めない。

移行前実績は`.private/analytics-review-2026-10-17.md`を基準とし、取得期間と未確定事項を非公開記録へ保持する。実装時に新たなアクセス取得・GA4設定変更は行わない。本番反映と通常利用の受信確認後14日・28日で旧新URL合計・主要検索語別の検索流入、概要表示、企業詳細への同一セッション遷移を比較する。UI版の異なるイベント件数を直接人数・転換率としない。少数なら延長する。流入維持は保証せず、片方のURLの減少だけで失敗としない。

恒久転送は継続して保持。commit・pushは運営者が行い、本番反映日・HTTP転送・受信・インデックス移行・観測開始日を別々に記録する。自動取得・通知は追加しない。
