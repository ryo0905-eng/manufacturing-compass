# Tool Navigator MVP

更新日: 2026-10-29

半導体・製造データの課題から、ソフトウェアの役割と導入前の確認事項を整理する。製品の優劣や適合率を推定しない。掲載対象は機能を確認できた少数のソフトウェアで、個別構成・契約・装置との接続は導入前に確認する。

## シナリオと操作

- 歩留まり：課題、コード経験、データ規模を変更して候補の理由と未確認事項を読み、3製品を比較する。
- 装置ログ：課題を選ぶと収集・ETL・基盤・可視化の領域を強調。マップ上の製品から同領域の代替候補と別領域の組み合わせ候補を探索する。接続可能性を保証しない。
- Cpk：無料Cpkツールへの入口と工程能力を確認した製品を表示。生データのPp/Ppkと短期標準偏差を用いたCp/Cpkを区別する。管理図とDOEもマップから案内する。

## ワイヤーフレーム

```text
PC:      課題・条件       | 候補と無料ツール      | 比較表・表示設定
        （必要／希望）    | 理由・確認事項       | 共有URL
                         | 6領域のマップ → 選択製品の詳細       |
        [固定トレイ：選択中の製品 / 比較へ]
スマホ:  [1 条件] [2 候補] [3 比較] [マップ]
        [選択中のステップ]   [固定トレイ]
```

## 実装と境界

目的で候補を絞る。必要・希望機能と環境・スキル・規模は確認済みの事実と未確認事項として説明する。任意の「確認済みのみ」フィルターは必要機能を全て確認した候補を表示し、非表示の候補を非対応とは扱わない。表示順は固定。マップは役割の共通性と相違で候補を案内し、競合・補完は用途上の候補であって実際の互換性・接続を意味しない。

URLには固定IDのみを保持し、読込時に許可リスト、重複と最大4件を検証する。比較項目、差分強調、絞り込みを復元する。イベントは診断目的、製品ID、操作、件数、共有成否のみ。個人情報、自由入力、入力データは扱わない。データは静的で読込中・空状態・コピー失敗時のURL表示に対応する。通信に依存しないため製品取得エラーは発生しない。

公開出典は各製品の公式ページで確認し、台帳の確認日と共に詳細画面に表示する。価格は体系や確認事項のみとし、実価格を推定しない。比較項目は機能・契約の全範囲を網羅しない。
