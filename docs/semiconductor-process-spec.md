# 半導体ができるまで：触って分かる工程図鑑

最終更新日: 2026-09-22

## 目的・範囲

`/tools/semiconductor-process` は、企業名や工場名は知っていても工程をイメージできない人に、全体像と加工の変化を約5分で伝える教育用教材。6地点の全体像から、ウエハ準備8工程、薄膜加工8工程、配線づくり＋CMP7工程、切り分け・組立7工程、ウエハ検査4工程、最終検査4工程へ入る。後工程単独でも利用できる。各体験は約3〜5分。ウエハ全体は奥行きのあるSVG、加工部分は2D断面とし、実物を切断する操作と混同しない。

全体像は設計、ウエハ準備、素子・配線、ウエハ検査、切断・組立、最終検査。初期選択は素子・配線で「一つの加工を拡大してみる」へ案内する。「切り分け・組み立て」から後工程体験に入り、それ以外は短い図解であり、全製造工程の操作シミュレーションではない。前工程にはウエハ上の配線も含まれ、BEOLと組立中心の後工程を区別する。検査は途中にもあり、区分・順序は製品・パッケージで異なる。

## 断面・技術表現

8工程は、洗浄→成膜→レジスト塗布→露光→現像→エッチング→レジスト除去→加工後洗浄。ポジ型の代表的な加工例で、熱処理、選択比、レジスト消耗、実物寸法、反応速度を簡略化する。

- 露光はレジストの状態だけを変え、形状を変えない。マスクは離れた位置に置き、光学系を介した投影として表現する。
- 現像は露光領域のレジストを除き、加工対象膜を残す。エッチングはその開口下の膜だけを減らす。この例では基板を保持し、レジストの消耗を省略する。レーザーで削る表現は使わない。
- 洗浄は粒子・残留物の表示量だけを変える。作った形を除去しない。図の粒子は模式表現で、全汚染が水で除去できる意味ではない。
- シリコン（斜線）、加工対象膜（点）、レジスト（横線）、反応領域、不要物に一貫した色・凡例を使う。「なぜここだけ削れる？」で保護領域と開口を強調し、「なぜまた洗う？」で不要物を強調する。
- 加工後は別の完成構造の概念図へ切り替える。この8工程だけで動作チップになることや、同じ模様を重ねるだけで完成することを示唆しない。

全体と工程ごとに一次情報・関連記事を対応付ける。企業の図版は複製せず独自SVGを使う。加工対象材料や特定装置の性能は仮定しない。

## 状態・再生・アクセシビリティ

図は工程番号＋0〜1の進行度から純粋関数で決定する。8工程の各開始状態は前工程の完成形と接続し、巻き戻しやジャンプでも累積演算しない。アニメーションの進行度を時間・加工量として扱わない。

- 再生は各工程2秒、途中からの再開は残り時間だけ。自動で次工程へ進まない。再生中の再生ボタン連打は無視する。
- 一時停止、再開、同じ加工の再生、前・次の工程、任意工程への移動、進行度スライダーを提供。スライダー操作は停止して指定状態を描く。
- 「次の工程 →」は両体験とも移動と再生を1操作で行う。低モーション設定では次工程の完了図へ切り替える。前の工程・工程一覧からの選択は加工前で停止する。
- 工程変更時は旧工程の再生を破棄。全体像への移動・タブ非表示・pagehide・教材領域が画面外になった場合に停止。自動復帰しない。unmountでRAF・監視・イベントを解除する。
- 再生トークンが一致しない古いRAFコールバックは破棄。フレームごとのstate更新はするが、計測や読み上げを行わない。
- prefers-reduced-motionでは再生・再開・再生し直しで加工後の静止状態へ移る。スライダーは残す。再生中に設定が変わった場合も完了形へ切り替える。
- 工程移動後に作業領域へフォーカス。標準buttonとrange、44px以上の操作領域、可視フォーカス、SVG title/desc、模様付き凡例を使う。読み上げは開始・完了・停止・工程移動時のみ。
- 工程完了は進行度1へ到達した初回。スライダーでの到達も含む。薄膜加工8工程／組立7工程をそれぞれ全部見たときのみ、その体験の完了イベント。工程を飛ばして最後へ進めるので、まとめ画面の閲覧とは区別する。

## 第3弾：配線づくり＋CMP（2026-09-22）
