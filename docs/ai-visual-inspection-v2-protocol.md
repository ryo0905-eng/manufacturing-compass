# AI外観検査 v2：段階的な再検証

事前設定日: 2026-09-21。v1の結果・生成器・重みは変更しない。この文書はv2実行前の条件を固定する。

## 順序と判定

1. v2生成と監査。良否に共通の基板単位の明るさ倍率を用い、各撮影のノイズは同じ分布とする。模様不足は良品画像だけを変更し、不良画像は基準構成と完全一致させる。誤ラベルは画像を変えず学習マスクだけ変更する。分割単位は元基板。
2. 学習用の先頭12基板・48枚で動作確認。最大320更新、40更新ごとに学習画像で確認。汚れ・傷の平均領域IoUが各0.70以上、各欠陥の見逃し率5%以下、良品の過検出率5%以下が2回連続すれば通過。未知画像への性能とは呼ばない。失敗時は以降を実行しない。
3. 基準モデルのみ学習2,400枚・調整400枚。最大12エポック、毎エポック欠陥別IoU・見逃しと良品過検出を計算。調整群で汚れ・傷IoU各0.50以上、各見逃し率20%以下、過検出率10%以下を2回連続で満たせば早期終了。到達しなければUI・比較モデルへ進まない。この数値は教材の初期品質目標であり実工程の合格基準ではない。
4. 基準通過後に開発600枚を1回評価。同じ欠陥別基準を満たす場合だけ、同じエポック数と損失・モデル構造で学習構成の比較へ進む。シード17/29/43、画像数2,400を共通とする。しきい値は調整群で選び、開発評価では変更しない。
5. 最終600枚は上記の技術確認・設定固定後まで推論に使用しない。公開前の人間レビュー・ブラウザ確認は別工程。

## 学習と計算

モデルはv1と同じ16/32/64チャネルU-Net。入力uint8をfloat32 / 255へ変換。損失は正例重み12のBCEと、欠陥がある画像ごとに計算したDice損失の平均を加える。バッチ全体の領域合計だけで汚れ・傷をまとめない。これは改善仮説であり有効性を事前に断定しない。Adam、学習率0.001、シード17。少数確認はバッチ12、本学習は32。しきい値0.5、最小面積12を少数・基準確認に固定する。

1コマンド175秒で停止し、タイムアウト・未達後の設定変更による再試行は行わない。基準モデルは学習と調整だけで判断し、開発・最終の結果でチェックポイントを選ばない。

## 比較の継続条件の修正

偏り・誤ラベルがすべてのシードで必ず悪化することを必須にしない。基準モデルが傷を位置として検出できることを先に要求し、その後は固定した操作での変化、変化しない場合、逆転を全シードで記録する。同じ方向の効果を教材文言で断定する場合のみ、その再現性を要求する。v1を遡って合格に変更しない。

撮影条件と良否の独立性は固定の真偽値ではなく生成メタデータと画像変換の照合で検査する。モデル・データ・出力は `.cache/ai-visual-inspection/v2/` に分離し、Web配信しない。
