# 日本地図で探す半導体拠点アプリ

更新日：2026-10-20（UI・構成の更新日。全拠点・全案件の一括再確認日ではない）

## 目的と掲載範囲

国内半導体拠点を所在地・拠点種別・職種から探し、新設増設の節目を確認する。公開静的データは13社・28物理拠点と主要5案件。同じ敷地は1拠点とし、JASMの第1・第2工場は2案件として同じ拠点へ対応付ける。Rapidus IIMとキオクシア北上を追加。全国の工場や計画の網羅一覧ではない。

`/semiconductor-map`が探索アプリ、`/guides/japan-semiconductor-factory-projects`が案件比較・説明記事。両URL・検索意図・自己参照canonicalを維持し、リダイレクトしない。記事の案件別リンクと2件比較から、地図上の対象拠点・案件を直接開く。

## 画面と操作

- 1,200px以上：240pxのフィルター、可変幅地図、360pxの結果。ページ幅は最大1,600px。地図を閉じると一覧を広げる。
- 900〜1,199px：開閉式フィルター、地図と結果の2列。899px以下：地図を先に表示し、その下に結果。地図は高さ43svh、300〜520px。詳細はネイティブdialogの下部シート。閉じる・Escape・フォーカス復帰に対応する。
- 地図の移動・拡大縮小・全国表示、一覧とピンの選択連動。地図を動かすだけでは検索結果を変えない。重なるピンも一覧から選択できる。
- 会社・都道府県・状態・拠点種別は項目内OR、項目間AND。職種は単一選択。キーワードは企業名・拠点名・所在地・製品・関連職種。変更を即時反映し、条件チップと全解除を設ける。
- 地図・一覧・表・8地域のグラフは同じ結果から生成。拠点モードは物理拠点数、案件モードは案件数。地図は案件を物理拠点で重複排除し、座標確認済みだけを表示する。
- グラフの地域選択で都道府県条件を置き換える。他条件は維持する。0件の地域は操作不可。条件を外すチップも表示する。
- 詳細は所在地、役割、敷地内施設、節目、予定、出典、確認日、企業または公式サイトへのリンク。採用情報は独立した確認日・期限を維持する。

写真、投資額、金額・年の範囲検索、航空写真、産業集積エリア、アカウント、通知、保存、実行時住所検索を追加しない。

## データと座標公開条件

- CompanyLocationが物理拠点の正本。FactoryProjectにlocationId、facilityId、operationalStatus、milestonesを追加し、記事とアプリで共用する。milestonesはdateLabel、label、actual/planned、sourceNumbersを持ち、年月・年末などの精度を保つ。
- LocationCompanyは既存会社の識別・表示情報とRapidusを保持する。slugのない企業は詳細ページを新設せず公式サイトへ案内する。
- 拠点状態と施設・案件状態を併用する。稼働中の敷地に建設中の新棟があれば、両方の状態へ該当する。案件モードでは対象施設・案件の状態を使い、既存工場の職種を新棟へ推測で転用しない。
- 公式住所に付随する地図案内と施設名を照合した座標をagent-verifiedとして記録する。human-reviewedと区別し、確認日・出典・精度・根拠説明を保持する。2026-10-20の明示選択により、人による確認だけに限定した従来条件を変更した。
- 施設、地番、住居詳細の精度、有限の日本国内座標、確認済み状態、確認日、出典ID、根拠説明を満たすものだけピン表示する。画面中心、市区町村代表点、過去の照合専用座標をそのまま採用しない。
- 初回は9拠点の公式案内由来座標を登録。残る19拠点は一覧に残す。JASM熊本を含む未確認拠点は仮位置を置かない。掲載28拠点・地図表示9拠点を混同しない。
- 旧パイロットのQ地図・OpenStreetMap由来座標を本番へ移していない。住所ジオコーディングと新しい運用基盤は導入していない。

## 実装・URL・SEO

Leaflet 1.9.4を直接使い、React用ラッパーは追加しない。地図部分だけSSR対象外の遅延読み込みとし、拠点一覧・出典はSSRする。地図初期化を解除時に破棄し、ResizeObserverで表示幅変化へ対応する。タイル・地図ライブラリの失敗でも一覧と検索を維持する。

背景は地理院淡色地図をブラウザから取得。地図内に地理院タイルのリンクと小縮尺のShoreline出典を表示する。位置情報取得は要求しない。

既存prefecture・type・jobを維持し、company・status・mode・view・format・location・projectを有限値として共有する。複数条件は同じキーを繰り返す。view=regionsはmapと解釈。無効値は無視し、共有リンクは許可値から再生成する。自由入力検索語はURL・計測へ送らず、戻る操作でクリアする。条件変更は履歴へ追加し、popstateで復元する。

パラメータ付きURLはnoindex, follow、canonicalは全国URL。全国ページのタイトル・description・BreadcrumbList・ItemList・sitemap掲載を維持する。新しい都道府県ページは追加しない。記事の編集日と案件資料の確認日は分ける。

## 計測・検証・反映

既存location_map_location_openをpin/list/urlで区別し、有限の拠点・案件IDを送る。filter_useにcompany/status/region/clear、view_changeにmap/cards/tableを追加。mode_change、project_entry、official_clickを追加する。自由入力・座標・地図移動ログを送信しない。

単体テストは参照整合、複数条件、同一敷地と案件の計数、座標公開条件、URLの許可値と互換、SSR、metadata、CSSのpure mode。E2E仕様はPC・スマホのピン選択、条件変更、戻る・再読込、表、タイル失敗、JavaScript無効を対象にする。ブラウザ実行は明示確認依頼時のみ。typecheckは最大1回、各検証は3分以内。buildは明示依頼時のみ。

公開設定と本番反映を区別する。実装時点では本番反映日・実画面・検索効果を未確認とする。反映日の根拠を非公開に記録し、28日・56日後に両ページの検索クリックと詳細・公式情報への利用を確認する。
