# タグチメソッド体験：ばらつきに強い条件を探す

最終更新日: 2026-09-21

## 目的と範囲

`/tools/taguchi` は、架空の成膜工程で、通常環境の良さと誤差条件への強さを約5分で比較する日本語教材。静特性・望小特性のパラメータ設計に限り、タグチメソッド全体を網羅しない。既存DOEは効果・交互作用、BOは次の実験選び、このアプリは制御因子と誤差因子の関係を担当する。

実設備への推奨、物理的原因の確定、量産適合性、工程能力の判定をしない。動特性、望目・望大特性、許容差設計、損失の金額換算、CSV、AI、保存、アカウント、対戦、英語公開を含めない。

## 実験と進行

温度360/400/440℃、圧力40/60/80PaをL9第1・第2列に割り付ける。この2列は全3×3組み合わせであり、回数削減とは説明しない。原料特性の反応しやすさは低い/基準/高いの教材上の相対水準。実物の物性値・管理規格ではない。

| 段階 | 操作・データ | 累計実験数 |
| --- | --- | --- |
| ready → baseline | 通常環境で9条件を各1回。最初は条件c1を選択状態とし、実験後に本人が基準を選ぶ | 9 |
| baseline → stress | 基準を固定し、3原料状態×2反復 | 15 |
| stress → compare | 残る8条件×3原料状態×2反復 | 63 |
| compare → review | 基準・候補を各3原料状態×3反復で新規測定 | 81 |

compareでは候補を自由に変えられる。基準と同じ候補も許可する。段階ごとの実験は原子的に追加し、重複コマンド・古い画面のイベントでは再実験しない。81回は実験数でありクリック数ではない。

通常環境9観測は比較用54観測のSN比に含めない。確認は新規18観測とし、探索結果を再利用しない。比較を終えるまでSN比を表示せず、改善の有無によらず完了できる。

## 仮想装置と再現性

制御水準a,bと誤差水準zを−1,0,1として使用する。

```text
f = 1 + 0.25(a+1)² + 0.15(b+1)²
    + (1.5 − 0.5a − 0.3b)z² + 0.3(1−a)z
y = f + Uniform(−0.03, +0.03)
```

膜厚むらは「面内膜厚の標準偏差÷平均膜厚×100」の教材上の品質指標。面内の測定点は作らず、指標値を直接返す。面内のむら、原料状態による変動、測定ノイズを区別する。有限な今回の条件範囲で正の観測値を保つ。物理機構のモデルではなく、BOのモデル・条件・結果を引き継がない。

ノイズなしでは通常環境最良はc1（低温・低圧）、SN比最大はc5（中央・中央）。c9は平坦でも品質値が高くSN比は最良でない。「通常値の低さだけ」「平坦さだけ」で選ばない体験にする。

版 `taguchi-deposition-v1`、シード `20260921`。版・seed・phase/arm/condition/noise/replicateを含む実験IDをハッシュしてMulberry32の一様値を生成する。表示操作・実験の分割順で同じIDの測定値は変わらない。確認のphaseとbaseline/candidateのarmで乱数列を分離する。同条件の両群も異なるIDで別測定にする。実施順は測定と別のソルトでバッチ内をランダム化する。時間ドリフトはない。

## 計算・データ境界

- `types` は条件・水準・IDと観測型。観測は実験ID、段階、条件ID、原料水準、反復、群、実施順、値のみ。
- `simulator` は架空応答・測定・バッチ実施順。
- `analysis` はtypesのみに依存し、観測から集計・候補を生成する。真値は参照しない。
- `session` は予算と基準・候補の確定、解析失敗時の保持と停止。
- UIは取得済み観測と解析結果からグラフ・表を表示し、状態はメモリのみ。外部API・永続化なし。

望小SN比は `−10 log10(Σy²/n)`。54観測を各条件の6観測に分け、個々の観測の二乗を平均する。実装では大きな値の二乗のオーバーフローを避ける同値のスケーリング式を用いる。正規分布は仮定しない。負のSN比も正常、大きいほど良い。純粋なばらつきや合格確率ではない。

3原料状態は等重みであり、量産時の発生確率ではない。因子応答図はその水準を含む3条件のSN比の算術平均。各因子の最大水準を機械的に組み合わせず、実験済み9条件の最大SN比を候補として補助表示する。同点ではL9の行順を使う。本人の選択を上書きしない。

標準偏差はn−1で計算し、意図的に振った3状態を含む試験結果の散らばりと明記する。量産工程の標準偏差とは呼ばない。確認では各群9観測を使い、SN比の候補−基準の差も示す。差の絶対値0.10dB未満を教材上「差が小さい」とするが、有意差・同等性の判定ではない。

空、不正な水準バランス、重複実験ID、負値・非有限値、全0でSN比が無限大となる入力は解析エラー。計算失敗時は履歴を保持、解析・候補・派生グラフを停止し、再挑戦で初期化できる。捏造値での補完はしない。

## 画面と学習説明

中央は原料3水準×膜厚むらのSVGグラフ。基準は実線・丸、候補は破線・四角。各観測を小点、状態平均を大点で表示。線は測定水準の結線で中間値の推定ではない。初期9観測では中央の点だけを表示する。

原料3段階スライダーは取得済み測定を選択し、再測定しない。制御水準ボタンと3×3表で条件選択できる。詳細表で全観測と集計、折りたたみの因子応答図で水準別SN比を確認する。確認後は探索54観測と新規確認18観測を切り替え、常に対象を明示する。

スマホはグラフ→条件選択→実験ボタン。標準ボタン・range、focus-visible、直接ラベル、ライブ通知に対応。200ms未満の描画演出とreduced-motionでの無効化。グラフ以外でも数値と表を読めるようにする。

## 統合・計測・検証

Server Componentで概要・手順・用語・出典を初期HTMLへ出力。canonical、WebApplication、パンくず、sitemapと確認日を設定。ツール一覧で教育用表示、DOE・BOの読後から誘導、終了後はDOE・工程比較・安定工程の能力評価へ案内する。

イベントは `taguchi_started / taguchi_stress_completed / taguchi_candidate_selected / taguchi_confirmed / taguchi_retried / taguchi_related_clicked`。version/stage/source/destinationの固定分類だけ送信し、温度・圧力・観測値・履歴・seedを含めない。

`tests/unit/taguchi.cjs`：L9バランス、SN比の独立参照、81回・54観測・18確認の件数、基準状態の除外、乱数再現、バッチ分割と基準選択順への不変性、確認群の独立性、真値非参照、失敗時停止を検証する。

`tests/unit/taguchi-ui.cjs`：段階進行、基準固定、スライダーで測定不変、条件選択、同じ候補、探索と確認の切り替え、連打・リセット・失敗、計測制限、SSRを検証する。実ブラウザ検証とは区別する。

公開文面の人間レビュー、製造経験者3人による約5分の試用、実機スマホ・キーボード・reduced-motion確認は別途残す。3人には誤差因子を振る理由、普段の良さと変化への強さ、SN比だけで量産適合性や再現性が確定しないことを確認する。ブラウザとbuildは明示依頼時のみ。typecheckは最大1回。
