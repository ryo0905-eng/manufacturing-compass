# AI外観検査 v2：学習構成の比較条件

固定日: 2026-09-21。追加学習で基準モデルが通過したため、ユーザーの「つぎ」に基づき比較へ進む。過去の未達記録を保持する。

- v2の既存データを使用。4構成（balanced / dirt-biased / normal-poor / label-errors）、各2,400枚、シード17・29・43。同じ初期化、TinyUNet、損失、Adam 0.001、バッチ32、10エポック・750更新。構成別の早期終了や追加学習はしない。
- balancedの17は既存の10エポック重みをハッシュ確認して再利用。それ以外はランダム初期化。既存実験のエポックごとの調整評価は勾配・乱数に影響しない。今回の評価は学習終了後に行う。
- 欠陥スコア0.5、最小面積12を固定。同じ開発600枚、正解マスク・ラベルで全モデルを比較。各コマンド175秒で停止し、失敗時の別設定による再試行は行わない。
- 基準モデルの再現性は各シードで汚れ・傷IoU各0.50以上、各見逃し率20%以下、良品過検出率10%以下を満たすか報告する。平均だけで未達シードを隠さない。
- 構成の影響は同一シードの基準との差分と、画像ごとの判定変化を記録。汚れ偏重は傷の見逃し・IoU、良品不足は過検出、誤ラベルは傷の見逃し・IoUを主に確認する。悪化を必須条件にせず、不変・改善も記録する。3シードで方向が一致した場合のみ、この設定で繰り返し見られた傾向と呼ぶ。統計的有意性や一般的な方式の優劣は主張しない。
- 将来の教材候補は結果の良し悪しで選ばずシード17とする。ONNXとPyTorchの先頭24枚のスコア誤差（1e-4未満）・後処理マスク一致も全モデルで確認。
- 今回は学習構成とシードの比較まで。照明変化、ルール比較の再評価、背景交換、最終600枚、ブラウザ性能、人による試用は別の未完了項目として残す。
