# AI外観検査 v2：ルール比較・明るさ変化

固定日: 2026-09-22。ユーザーの「tugi」に基づき、16エポックの4構成×3シードを変更せず評価する。

- 共通画像はv2開発600枚、正解は固定。画素へ倍率0.7・1.0・1.3を掛け、丸め・0〜255へのクリップを行う。同じ変換画素を両方式へ渡す。倍率は結果を見る前に固定し、失敗しやすい条件だけを選ばない。欠陥の正解は変換後も保持し、白飛び等で情報が失われた場合もそのまま報告する。
- 基本ルール: 暗い画素の二値化、8近傍連結領域、最小面積12。改善ルール: 17×17の局所平均（端は複製）と画素の差で検出。照明むら補正はこのルールの内部処理であり、AI入力に別の補正画像を与える比較ではない。
- ルールしきい値は調整400枚・倍率1.0だけで決める。基本は32〜224を16刻み、改善は8〜80を8刻み。見逃し率＋過検出率が最小、同点なら過検出率が小さい方、それも同点なら数値の小さいしきい値を選ぶ。この等重みは教材の比較基準であり、現場の費用比ではない。
- AIは既存のスコア0.5・面積12を保持。倍率1.0のスコアはモデル・データ・後処理条件を照合して再利用し、0.7と1.3は実画素からONNXで再推論。全12モデルを記録する。基準に合わせて偏りモデルのしきい値を変えない。
- しきい値曲線はルールの上記グリッドとAIの0.1〜0.9（0.1刻み）、倍率1.0の開発群で記録する。曲線から設定を選び直さない。選択済み設定の一点だけで方式全体の優劣を主張しない。
- 単純な汚れの場面はメタデータで「平坦面、傷以外」を選び、同じ固定設定で集計。基本ルールの見逃し率・過検出率が各5%以下なら、この限定場面で有効と判断する。基準を満たさなくても別設定で再試行しない。
- 基本ルール＋AI、改善ルール＋AIの「どちらかが不良なら止める」も同一画像の実結果から集計する。全体・欠陥種類・模様別の見逃し／過検出・母数・領域一致、倍率1.0から判定が変わった画像IDを記録する。
- 各コマンド175秒上限。失敗時は別設定で再試行せず、記録を保持。保存先 `.cache/ai-visual-inspection/v2/lighting/`。旧成果物を上書きしない。実行時間はネイティブCPUの値で、ブラウザ性能とは呼ばない。
- 今回は明るさ倍率の検証であり、全撮像条件への頑健性を確認したとは言わない。背景交換、最終600枚、Worker/WASM、実端末、人による試用、UI・公開は未実施のまま残す。開発600枚は確認済みであり未知データではない。
