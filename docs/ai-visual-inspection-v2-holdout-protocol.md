# AI外観検査 v2：背景交換と固定した最終評価

固定日: 2026-09-22。ユーザーの「tugi」に基づく次段階。モデルの追加学習・しきい値変更はしない。

1. 開発150基板の背景を、同じ開発群内の次の基板・2つ先の基板へ循環置換する。元画像の欠陥形状・位置・濃さ・撮影倍率・撮影ノイズを維持し、背景だけを交換。元背景で再描画した600枚が既存画像と画素単位で一致することを先に検査する。画像差分の貼り付けは使わず、元生成器の欠陥信号を描く。背景ノイズは背景とともに移る。2置換はそれぞれ600枚、同じ良否・正解マスク。背景の種類は置換先の値を記録する。
2. 基本112・補正8、最小面積12。全12モデルは0.5・面積12、同じ16エポック重みを使用。全モデル・両置換を記録。判定が背景によらず完全一致することは要求しない。基準3シードが各置換で汚れ・傷IoU各0.50以上、各見逃し率20%以下、良品過検出率10%以下なら、この背景依存点検を通過とする。これは任意の背景への頑健性の証明ではない。
3. 最終評価を開く前に、再描画一致・データ監査・既存の基準3シード通過・単純汚れルール通過・全12モデルの背景評価完了・基準の背景基準通過を確認する。モデル、処理ソース、データ、ルール設定、プロトコルのハッシュをロックファイルへ固定する。未達なら最終600枚は開かず、別設定で再試行しない。
4. 通過時だけ既存の未使用final600枚を評価。基本・補正ルール、全12モデル、実結果によるOR併用を倍率0.7・1.0・1.3で記録する。通常倍率の基準3シードには同じ基準、単純汚れの基本ルールには見逃し・過検出各5%以下を適用する。明るさ変更や偏りモデルの悪化はそのまま記録し、全条件で基準モデル並みの性能を要求しない。先頭24枚のPyTorch/ONNXスコア最大差1e-4未満と領域完全一致も各モデルで確認。
5. finalの最初の処理前に開封台帳を作成。一度開いた事実は戻さない。結果は上書きせず、しきい値曲線の再探索や設定変更はしない。開封後の結果から開発変更する場合は、この群を開発用へ移し、新たな独立評価群が必要であることを記録する。表示候補は事前指定のシード17。
6. 各コマンド175秒上限、失敗・停止時に別設定でやり直さない。保存先 `.cache/ai-visual-inspection/v2/holdout/`。結果には全条件、領域、母数、種類・模様別集計、ハッシュを保持。最終評価の成功も実工場の保証や公開承認ではない。Worker/WASM、ブラウザ・実端末、人による試用、UI・公開は別段階。
