## 目的と実装ゲート

架空の成膜後基板表面について、同じ画像に対する限定したルール処理と小型セグメンテーションモデルを比較する。合成画像は実際の光学系・製品規格を再現しない。約5分の日本語教材とし、方式全体の優劣、実工場での性能を保証しない。

最初にデータ生成、学習、調整、開発評価を実行する。単純な汚れにルールが有効で、データ構成やしきい値による複数画像の判定・領域の変化が3学習シードで確認できた場合のみUIへ進む。満たさない、または実行できない場合は未達を報告し、公開画面・導線は追加しない。最終評価は設定を固定した後だけ使用し、その後の変更に使った場合は開発評価へ移す。

## 検証仕様

- 128×128画素のグレースケール。良品は平坦・濃淡むら・規則模様、不良は汚れ・傷。元基板ごとに良品2枚、汚れ1枚、傷1枚を生成する。模様・照明・位置は良否から独立。
- 学習2,400枚、調整400枚、開発評価600枚、最終評価600枚。元基板・背景・欠陥形状テンプレート・変換派生は同一分割にまとめる。画像ハッシュ、生成由来、縮小画像の近似一致を検査する。単純な無地面の近似は別途報告し、未知の材質への一般化とは呼ばない。
- 学習構成は balanced / dirt-biased / normal-poor / label-errors の4種類。各2,400枚、同じ構造・初期化シード・学習手順。シードは17、29、43。構成間の画像重複は比較のため意図的に許容し、学習と評価の重複は禁止する。
- dirt-biasedは傷を汚れに置換。normal-poorは学習画像全体で規則模様を除き、背景と良否の交絡を避ける。label-errorsは傷の半数の学習マスクを空にする。評価の正解は変更しない。
- AIは16/32/64チャネルの2段U-Net、入力0〜1、出力sigmoidの欠陥スコア。事前学習済み重みの外部流用なし。推論入力にラベル・生成パラメータを含めない。
- ルールは暗い画素の二値化、8近傍連結成分、最小面積。補正版は局所平均との差を用いる。AIも同じ連結成分・面積基準から良否を導出。
- 調整群のみで見逃し率＋過検出率の最小値を選ぶ。同値では過検出の少ない点、設定順とする。この重み付けは調整用であり現場の採否を決めない。評価ではしきい値別の両指標も残す。
- 明るさ倍率0.7 / 1.0 / 1.3は評価前に固定。0〜255に丸め・飽和し、実画素を再推論する。正解マスクは維持する。
- 欠陥領域IoU、見逃し・過検出と母数、欠陥・模様別集計、背景差し替え比較、モデル容量、処理時間を保存する。確率校正済みとは表現しない。
- 1コマンド180秒未満。時間超過した検証は停止・未完了として報告し、設定を変えて再試行しない。

## ゲート通過後の画面・統合

公開プライバシーポリシーへの追記は、実際のブラウザ実装と同時に行う。技術検証だけの段階では未提供の機能を公開済みとして記載しない。開発時の合成画像・重み・判定はローカルに保持し、外部AIへ送信しない。公開後の方針は、画像・判定・学習状態の非送信、操作状態のメモリ保持、固定カテゴリ計測に限定する。

`/tools/ai-visual-inspection`。Server Componentの短い概要・使い方・限界・出典・更新日と、Client Componentの5段階操作を分離する。汚れ→模様と傷→学習例の異なるモデル→明るさ→別画像で確認と振り返り。スマホ上下・PC左右の同一画像比較、実出力の領域重ね、誤判定の絞り込み・拡大、キーボード・読み上げ対応。

常時表示は「不良品を通した数／不良品数」「良品をはじいた数／良品数」。詳細に混同行列と欠陥別結果。AIは4モデルの切替で、その場で学習したとは表示しない。代表例と実学習枚数を示す。最終確認では設定を固定し、再挑戦しても確認済み画像を初見扱いにしない。

処理はWorker内のONNX Runtime Web・WASM単一スレッド。画素・設定のみを推論へ渡し、真値は集計に分離。要求IDで古い結果を破棄。スコアをメモリに保持し、しきい値だけなら再推論しない。全画像の評価完了時に集計を一括更新し、失敗は未評価とする。モデル・WASMは同一サイトから遅延取得。外部API・アップロード・永続保存なし。

目標はモデル1MB以下、初回追加転送15MB以下（圧縮後）、プレビュー100ms以下、スマホ選択画像500ms以下、24画像3秒以下。未測定の目標を実績と表記しない。

併用は両方式の判定のORだけ。採用候補はルール／AI／併用／追加検証、採点なし。設定作業、データ収集、領域ラベルの準備負担を併記する。GRRは連続値の測定評価であり属性の良否判定と混同しない。

公開前に製造経験者3人の試用、画像・ラベル・文面の人間レビュー、依頼時のスマホ・キーボード・実端末性能確認を行う。未確認のまま公開可とはしない。canonical、WebApplication、パンくず、sitemapと既存ツール入口・検査解説への導線を用意する。検索需要は未検証。計測は固定カテゴリのみで画素・判定値・履歴を送信しない。
