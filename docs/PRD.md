# Product Requirements Document

最終更新日: 2026-09-21

## プロダクト

- サービス名: Manufacturing Compass
- 中心機能: インタラクティブ実務学習ツール、技術ナレッジ、Career Compass
- 表示上の説明: 製造業エンジニアの、技術とキャリアの次の判断を支える実務プラットフォーム

「市場価値診断」「採用可能性診断」「AI 診断」を正式名称にしません。実装内で使うスコアは、経験・実績・スキル・目標を棚卸しするための「転職材料の整理度」であり、人や企業による評価を示すものではありません。

## ミッション

製造業エンジニアの、技術とキャリアの判断をもっとわかりやすくする。

製造技術では、解析結果を出すだけでなく、何を疑い、何を追加確認し、どう判断するかを操作しながら学べるようにします。キャリアでは、製造業で積んだ経験を半導体業界の言葉へ置き換え、今の経験との接点、準備すると広がる選択肢、今日できる行動まで整理します。

## 解く課題

- 半導体の企業分類、工程、装置、材料、職種の関係が分かりにくい
- 自分の経験を、半導体求人で伝わる言葉へ置き換えにくい
- 今検討しやすい職種と、準備が必要なストレッチ目標を区別しにくい
- 求人票、職務経歴書、英語、勤務地、働き方の何を確認すべきか分からない
- 転職エージェントへ何を相談すればよいか分からない
- 技術情報と転職情報が分断され、企業研究につながりにくい
- Excel、JMPなどで解析結果を出せても、手法の選択、前提条件、結果の解釈、次に確認することを学びにくい
- 製造技術の解説は読む教材が中心で、条件を動かして判断の変化を体験できる日本語教材が少ない

## 対象ユーザー

- 半導体業界への転職を考えている社会人
- 生産技術、品質保証、設備保全、製造、機械・電気・制御設計、技術営業、FAE、製造DXなどの経験者
- 電子部品や他の製造業での経験を半導体へどうつなげるか迷っている人
- 今すぐ転職したい人と、半年後・1年後へ向けて準備したい人
- 製造技術、品質管理、統計手法を学び直したい実務者と若手エンジニア

## 中心価値

### 1. 技術の判断を学ぶ

計算値だけを返さず、条件を動かすと数値・グラフ・判断がどう変わるかを示します。正常な状態、意図的に加えた異常、考えられる原因、次に確認するデータを一つの操作体験でつなぎます。

Excel、JMP、Minitabなどの解析ソフトを置き換えません。専用ツールを正しく使う前提となる判断を学ぶことを目的にします。

### 2. 経験の翻訳

仕事内容を作り変えるのではなく、担当工程、改善実績、装置・品質・顧客対応、データ活用などを半導体職種で伝わる表現へ整理します。

### 3. 現在地と準備の分離

今の経験と接点のある職種・企業例と、追加経験を積んだ後に検討しやすくなる選択肢を分けます。「無理」「不足」と断定せず、何を準備するとルートが広がるかを示します。

### 4. 次の行動

今日15分でできること、30日、3か月、半年、1年の準備を提示します。必要な場合だけ、相談論点を整理して転職エージェント比較へつなぎます。

### 5. 根拠となる情報

企業、職種、工程、装置、材料の記事を、Career Compass の結果や企業研究を理解する根拠として提供します。事実、参考値、運営者の実体験、編集上の提案を区別します。

## 現行機能

### EFEM英語版の限定実験

- `/en/guides/semiconductor-wafer-handling-efem-manufacturers` の1本で、英語で半導体を学ぶ学生・若手技術者の検索需要を検証する。
- 日本語版の既存改善を優先する。2026-09-21の追加指示でCpk英語版を別の実験対象に追加。同日の追加指示でOEE・ラインバランス・工程条件比較の3本を実務ツールの追加実験とする。業界地図、記事一覧、その他の記事・ツールの英語化は保留する。
- 英語記事は公開情報に基づく技術解説。国内転職・講座の広告CTAは置かず、日本語へのリンクは遷移先言語を明示する。
- 英語版も公開情報記事の標準手順に従い、用語・出典・原文との整合を確認後に公開する。人間確認を一律の条件にしない。既存の確認日フィールドは実施内容に沿って記録し、未実施の人間確認を捏造しない。明示的な下書き指定や未確認の重要事項がある場合はnoindex・一覧非掲載にする。
- 目的は英語記事の検索流入。英語URLの閲覧と海外アクセスを分け、言語切り替えを獲得成果として足さない。評価手順は `docs/seo.md` に従う。

### 実務ツール

- 日本語Cpkの計算ページと、結果の読み方を説明する技術記事を分ける。`/guides/cpk-low-causes` は架空の平均・工程内標準偏差の3例から中心ずれとばらつきを比較する記事で、2026-09-21の運営者の公開承認によりpublishedへ切替済み（本番反映は別途確認）。新しい計算機能や工程条件の自動推奨は追加しない。

- 英語実務ツールの追加実験は `/en/tools/oee`、`/en/tools/line-balance`、`/en/tools/process-comparison` の3本に限定する。既存計算と日本語URLを維持し、UI・エラー・図表・コピー・PNGを英語化する。新しい計算機能、英語一覧、自動言語転送、広告CTAは追加しない。
- 対象は製造・品質を学ぶ学生と若手技術者。OEEは改善条件の推定比較、ラインバランスは手動再配分、工程条件比較は記述統計に限定し、生産増・自動最適化・有意差や因果関係を保証しない。
- 追加3本は2026-09-21の運営者の公開指示を受け、個別の確認者・確認日・公開日・公開状態を設定済み。検索・sitemap・日英言語リンクを有効にする公開実装状態。本番反映日は別途確認する。

- Cpk英語版（`/en/tools/cpk`）は計算・学習の両モードを提供する。日本語と同じ計算式・サンプル値・状態管理を使い、入力、分析、エラー、ヒストグラム、コピー、学習説明を英語化する。
- 英語Cpkは2026-09-21の運営者の公開指示を受け、確認日・公開日・公開状態を設定済み。検索・sitemap・日英言語リンクが有効になる公開実装状態とし、本番反映日は別途確認する。国内向け広告CTAは置かない。
- データはブラウザのメモリ内だけで扱う。言語切り替え時に入力を引き継がず、計測へ送信しない。英語の既存Cpkイベントへ固定値 `locale=en` を付けて区別する。

- 工程条件の比較ツール（`/tools/process-comparison`）
- プロセス・生産技術者が2条件の実測値を各2〜10,000件貼り付け、平均・中央値・標本標準偏差・最小最大・共通規格内件数と割合・平均差B−Aを比較する
- 共通軸・共通区間の相対度数ヒストグラム、表のTSVコピー（失敗時は手動選択）、PNG保存を提供する。規格境界は規格内に含める
- 入力変更時は結果を破棄し、再比較する。入力・結果・条件名はメモリ内のみで扱い、外部送信・保存しない
- 記述統計の整理・報告を目的とし、有意性・同等性・因果関係・採用可否を自動判定しない。検定、信頼区間、対応ペア解析、3条件以上は対象外
- 実データ比較は学習シミュレーションとは別用途。初期状態は空入力とし、明示操作で架空サンプルを読み込む
- 試用目標：対象技術者3人が説明なしで比較から資料への貼り付けまで完了し、2人以上が別の比較にも利用したいと回答する。実施・需要検証は未完了

- Cp・Cpk計算ツール
- 生データは全体の標本標準偏差からPp・Ppk、別途求めた短期標準偏差はCp・Cpkとしてブラウザ内で計算する
- 固定サンプル、ヒストグラム、ルールベースの分析コメント、結果コピーを提供する
- 入力した測定データをサーバー、データベース、Analyticsへ送信・保存しない
- 工程の安定性、分布、測定システム、個別の要求水準を含めた判断の代替にはしない
- 実験計画法（DoE）学習ツール
- 主効果、交互作用、反復、ランダム化、ANOVA、p値、効果量、残差、確認実験をブラウザ内で順番に学ぶ
- 完全実施要因計画と直交表の実験回数・情報量を比較する
- 入力・操作状態は保存せず、表示結果を実工程の条件決定に直接使用しない
- Gage R&R学習ツール
- 交差型の10部品・3測定者・2反復を使い、部品差、繰返し性、再現性、部品×測定者交互作用を操作して学ぶ
- ANOVA法の分散成分、%Study Variation、%Contribution、%GRR、ndcをブラウザ内で計算する
- 10%・30%を絶対的な合否基準にせず、測定用途、調査部品、顧客・社内基準と合わせた判断を促す
- 歩留まり解析ツール
- 日別の良品・不良品個数をブラウザ内で集計し、基準期間を固定したp管理図、製品別・装置別比較、製品構成比だけを変えた想定歩留まりを表示する
- 全体推移は参考表示とし、製品選択時だけ正式な悪化シグナルを判定する。原因は自動特定せず、保全・材料・条件変更など次に照合する記録を整理する
- 固定形式CSVを検証して読み込めるが、入力データ、製品名、装置名、日付、個数、ファイル名を保存・外部送信しない
- 歩留まり原因調査ダッシュボード
- 固定の架空半導体工場データを使い、歩留まり推移、不良内訳、製品・装置、ロット、工程条件、変更履歴を連動させ、別管理の確認実験までをガイド付きまたは自由探索で体験する
- 観察データの偏り、原因候補、確認実験による検証を区別し、実在企業のデータや固有情報、実データ接続、汎用BI編集機能を扱わない
- 山積み表・ラインバランスツール
- 工程別の作業時間、タクト超過、最長工程を可視化し、作業の所属変更と比較基準による再配分比較をブラウザ内で行う
- OEE改善シミュレーター
- 時間稼働率、性能稼働率、良品率、OEEを計算し、停止・速度・不良の改善条件から推定良品数を比較する
- 偏り、直線性、長期安定性、枝分かれ型、属性一致性分析は初期版の対象外とする

### 製造技術者サバイバル

- `/games/process-engineer-survival` で「2台の異常。原因は1つ？」を体験する原因調査プロトタイプを提供する。稼働90秒＋時間制限のない調査とし、実プレイは90秒を超えることを明示する
- B/Cの同時異常を、正常なA、材料履歴、温度、共通冷却流量、比較試験から調べる。初回は冷却系、再挑戦では材料の別原因ケースを選べる。原因は開始時に固定し、調査前に正解箇所を強調しない
- 停止、再起動2秒、材料切替3秒、保全依頼5秒、試運転4秒を区別する。誤った対策では改善せず、適切な対策後は再発しない。仮説選択や全情報収集を解決条件にしない
- 調査パネルでは時計・製品・作業が止まり、作業確定後に進行する。長押し万能修理、HP/SAN/Boss、連続ボーナス、旧固定案件スケジュールは使わない。移動とダッシュは維持する
- 製品は設備・材料の印を持ち、各設備6秒で1個の生産・検査・搬送を表す。停止中は仕掛品も止まる。試験品や作業前に保留した未検査品は納入数に含めない
- B/Cそれぞれの対策後確認と良品20個で目標達成。90秒で終了し、未達でも行動記録と確認結果を持ち帰れる。品質・復旧・生産を分けて評価する
- 工場、人物、条件は架空。保全は依頼として抽象化し、全数判別など教材上の簡略化を明記する。実工程の安全手順や原因証明を保証しない
- フォーカス喪失・非表示で一時停止し、明示再開する。プレイ状態はメモリのみ。計測は版と固定IDのみで、自由入力や個人情報を追加しない
- リザルトから既存の管理図、歩留まり解析、原因調査、DoEへ接続する。コード検証と面白さの検証を分け、製造経験者・未経験者を含む3人のプレイテスト通過前は追加ステージや3分版へ拡張しない

実務学習ツール共通要件:

- 正常状態から始め、ユーザーが異常や条件差を加えられる
- 数値、グラフ、判断理由を同時に更新する
- 自動判定だけで終わらず、考えられる原因と次の確認を示す
- 統計的判断と工程上の重要性を区別する
- 学習用モデルの前提、適用範囲、限界を明示する
- 操作しなくてもページ本文から中心概念を理解できる

### Career Compass

入力:

- 現在の職種領域と専門性
- 経験年数
- 半導体との接点
- 改善・立ち上げ・主導経験
- 成果の説明方法
- 関係者の範囲
- 英語力
- 専門スキル
- 現在年収帯（任意）
- 働き方の希望
- 転職の狙い

出力:

- 経験と接点のある半導体職種
- 半導体向けに伝えやすい強みと整理ポイント
- 転職材料の整理度と内訳
- 職種別の参考年収帯
- 経験と接点のある企業例
- 今日、30日、3か月、半年、1年の準備
- 職務経歴書で先に整えること
- 転職エージェントへ相談する論点

制約:

- 回答と結果をサーバーやデータベースへ保存しない
- 静的ルールベースで生成する
- 合否、選考通過率、企業評価、個人の市場価値を判定しない
- 参考年収帯は固定参考帯であり、提示額や昇給を保証しない
- 現在年収は差分表示だけに使い、参考帯の算出には使わない

### 日本の半導体企業・拠点マップ V0

勤務地から半導体企業を探す全国ハブ `/semiconductor-map` を、10社・24拠点の公式確認済みデータから段階的に実装します。

- V0は都道府県選択、拠点一覧、検索、拠点種別・職種による絞り込みを提供する
- 拠点の存在・役割と、期限付きの採用確認状態を別データとして扱う
- 初期HTMLで全公開拠点と出典・確認日を読める構成にする
- 座標、施設ピン、背景地図、求人API、応募機能はV0へ含めない
- 都道府県別の固定ページは、拠点数、複数企業、地域固有情報、検索需要を満たすまで作らない
- 正確な施設ピンはV0の利用を確認後、公開する座標を人が確認できる地域だけV1で検討する

2026-09-05時点では、型、10社・24拠点の静的データ、期限付き採用シグナル、取得・検査関数、全国の静的一覧、検索、都道府県・拠点種別・職種の絞り込み、座標を使わない都道府県選択図、全国ページのSEO設定、既存ページからの内部導線、有限値だけを送る拠点マップ用イベントまで実装済みです。全国URLだけをindex可能にし、絞り込みパラメータ付きURLは `noindex, follow` とします。公開URLに対するDesktop Chrome・Pixel 7向けE2Eは合計14件すべて通過し、V0の公開基準を満たしました。
