# 半導体工場プロジェクトの2件比較

実装日：2026-09-26。本番反映・GA4受信は未確認。

## 対象と画面

既存 `/guides/japan-semiconductor-factory-projects` の5案件一覧の直後に追加。別URLや企業ペア別ページは作らず、記事のcanonical・公開設定を維持する。全5案件の一覧はServer Componentで出力し、JavaScriptなしでも読める。

初期状態は未選択。2つのselectで異なる案件を選び、明示的に比較する。同じ案件の選択肢を無効化し、ロジックでも同一・空・未知IDを拒否。選択変更で古い結果とコピー通知を消す。結果見出しへ移動・フォーカスする。

所在地、資料確認時点の段階、確認できた節目、今後の予定・未確認事項、補足、確認日を項目ごとにA/Bで表示。PCは2列、スマホは各項目内でA→B。着工・試作・量産・装置搬入を区別し、工程進捗率や企業の優劣に換算しない。未確認の量産日を推定しない。工程ノード・生産能力・採用情報は追加しない。

出典リンクと、既存データに対応する企業詳細・国内拠点マップへ接続する。工場の予定を求人や配属先とは扱わず、比較5案件すべてがマップにあると示唆しない。

## データと確認範囲

`src/data/factory-projects.ts` に既存記事の5案件と5出典を移し、記事一覧と比較で共用。記事更新日は機能追加日、掲載情報の確認日は2026-09-20を維持する。新たな進捗の包括的更新ではない。

2026-09-26に以下を再確認した。

- [TSMC 2025 Annual Report](https://investor.tsmc.com/sites/ir/annual-report/2025/2025%20Annual%20Report.E.pdf)：PDFの印刷ページ014–015付近の事業概要で、第1工場の2024年末量産開始と第2工場の2025年建設開始の記述を確認。
- [Rapidus IIM](https://www.rapidus.inc/iim/)：2025年4月の試作ライン稼働と2027年量産予定の区別を確認。
- [Kioxia・Sandisk共同発表](https://apac.kioxia.com/en-apac/about/news/2025/20250930-1.html)：2025年9月の稼働開始発表と、段階的な能力拡大方針を確認。
- キオクシア岩手の個別ページとマイクロン広島の日本語記事は、取得結果から本文を再確認できなかった。岩手は上記共同発表で主要な記述を照合。マイクロンは既存記事の2026-09-20確認情報を保持し、記事冒頭・比較結果・コピー文に再確認待ちを明示。公式本文の再取得による再検証は残る。取得できなかった資料の確認日を進めていない。

## コピー・計測

比較メモはA/Bの全項目・確認日・出典URLと注意書きを出力する。Clipboard API失敗時も読取専用textareaから手動コピーできる。コピー中の選択変更・再作成では改訂番号で古い通知を抑止する。保存・URL復元・アカウント・外部APIは追加しない。

`factory_project_compare` は固定action=start/compare/copy_success/copy_fallback、source_slug、ui_version=compare-v1のみ。startは最初の選択時にマウント中1回、compareは明示的な比較要求ごと。初期表示を利用に数えず、compareを読了や人数と扱わない。関連リンクは既存article_company_click/article_internal_clickを使用。計測の例外が比較・コピーを妨げない。

本番反映後28日間の比較要求・コピー・関連ページ遷移を観測する。低利用なら需要未検証とし、収益効果を断定しない。
