# 平均の測定計画ツール

実装日・式の出典確認日：2026-09-23。公開設定済み。本番反映・実ブラウザ操作・GA4受信は未確認。

## 対象と範囲

品質・生産技術担当者が、単一の平均の推定幅と測定負担を測定前に比較する日本語ツール。`/tools/measurement-planner`。想定標準偏差、左右それぞれの推定幅E、任意単位、任意の1測定秒数を入力する。独立した代表的な測定、平均の正規近似、想定標準偏差固定の概算。標準偏差の推定誤差、時間変化、相関、偏り、有限母集団補正は含めない。不良検出・合否・改善差の検出力・品質保証に転用しない。同じ試料の反復を独立した製品数とみなさない。

## 計算

95%固定、係数1.96。n=max(1,ceil((1.96σ/E)^2))、実現推定幅=1.96σ/√n、合計秒数=n×1測定秒数。σとEは正の有限数。時間は空欄を許可し、入力時は正の有限数。件数100万まで。超過・非有限結果はエラーにし、上限へ丸めない。3案はE/2、E、2E。比較案だけが範囲外ならその行に理由を表示し、基本計画は維持する。表示は有効数字6桁、件数の切り上げは丸め前に行う。

出典：[NIST/SEMATECH 7.2.2.2, Application — estimating a minimum sample size](https://www.itl.nist.gov/div898/handbook/prc/section2/prc222.htm)。同ページ後半の検定・検出力の式とは別。母標準偏差既知の式を使い、過去の標準偏差推定を代入した計画の不確かさを保証しない。

架空例σ=2 nm、E=.5 nm、30秒では62件、1860秒=31分、推定幅は.5以下。3案は246/62/16件、123/31/8分。精度を厳しくしたとき、想定ばらつきが増えたときに測定数が減らないことを検証する。

## 体験と導線

初期表示と「架空例を試す」は例と明示。編集直後に結果・コピー・エラーを消し、計算ボタンで更新する。コピーは前提・式・3案・出典・更新日を含める。Clipboard失敗時は手動欄、編集中に過去の非同期コピーが失敗しても古いコピー欄を復活させない。

Cpk・工程比較の日本語結果欄から別タブで接続。英語導線には未翻訳ページを加えない。入力データの自動転送はない。ツール一覧の自分の数値で使う分類に追加。結果から改善の差を見極める教材へ進め、単一平均と平均差の問いを区別する。canonical、index、WebApplication、BreadcrumbList、sitemap更新日、OG画像を設定する。

## 計測・配布

既存共通フックにmeasurement-plannerを追加し、experience_viewとtool_stepのstart/sample/calculate/error/resultを使用する。初期サンプルを成果に数えず、操作後の結果見出しの前景25%露出を結果到達とする。成功コピーのみmeasurement_plan_copied。入力値・単位・結果は送らず、localStorage・保存ファイル・URL埋め込みも追加しない。

公開後14日で検索とThreadsを分け、セッション単位の開始→結果→コピーを観測。流入が少なければ需要未検証。架空例の利用を業務利用と断定しない。サンプル選択は自動計算のためcalculateを経由しない。コピーは資料作成の手掛かりであり業務採用の証明ではない。

Threads素材：`public/images/measurement-planner-comparison.png`（1200×630、確認済み）。`node scripts/generate-measurement-planner-card.cjs` で同じ計算から再生成。PNG目視で日本語・数値・注記・切れがないことを確認。アプリ実画面の確認とは区別する。
