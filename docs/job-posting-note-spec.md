## 2件比較モード（2026-09-26）

初期表示は従来の1件。「2件を並べて確認」で求人A・Bの記載状況を8項目ごとに並べる。PCは項目内で2列、スマホはA→Bの縦並び。給与額や勤務条件の具体値を比較する機能ではなく、不明点と確認質問を整理する機能。会社名・求人本文・金額の入力は追加しない。

Aは1件モードの回答と共通、Bは別にメモリ保持。切り替えても両方の回答を保ち、結果・コピー通知は破棄して明示再作成する。各求人で1項目以上を未読以外にすると比較を作れる。片側未読なら作成不可。明示クリアは両方の回答を消すことを画面で説明する。

結果は各項目のA・Bの記載状況と、記載なし／曖昧な側の質問を表示。未読・記載ありには質問を付けず、未読項目を残す。同じ記載状況を同じ条件と見なさず、点数・おすすめ・優劣判定は出さない。コピーは項目別比較とA・Bそれぞれの確認ノートをまとめる。識別名はコピー先で本人が付ける。API失敗時の手動コピー、編集・モード変更後の古いコピー通知抑止を維持する。

比較の計測は `job_posting_comparison` と `ui_version=compare-v1`、固定action（view/start/result/copy_success/copy_fallback/reset）だけ。view/start/resultは各モードでマウント中1回。1件モードの既存イベントを維持し、両者を合算しない。項目・回答・比較の差・本文は送信しない。元からある選択を引き継いで結果を作る場合、比較モードのstartなしでresultになる場合がある。

公開URL・canonicalは維持。構造化データ・sitemapの更新日は機能更新日にし、参照元の確認日は独立した `sourceCheckedAt`（2026-09-23）のまま保持する。本番反映後28日間の比較利用・コピーを観測し、需要の判断とする。クリックやコピーを相談・応募・収益の発生とは扱わない。

## 提供範囲

`/career-consultation#job-posting-note` に8項目の選択式ノートを追加。企業比較とCareer Compass結果から接続する。既存の相談メモひな形と広告導線は維持し、結果から相談ひな形へ進める。独立URLや求人データ連携、会社名・経歴・金額・本文の自由入力は追加しない。

仕事内容、必須／歓迎要件、初期配属、契約／試用期間、時間／休日、出張／交替勤務、給与内訳、選考準備を確認する。勤務地・業務・時間・出張・給与の質問文は既存の転職の軸データを再利用。項目・質問は編集上の相談例であり、公式の網羅的チェックリストや法律適合性の判定ではない。

## 状態と出力

初期値は「まだ読んでいない」。記載あり・記載が見つからない・意味が曖昧を区別する。1項目以上読んだ状態なら途中でも明示作成できる。未読は欠落と見なさず、コピー文でも別欄に残す。記載ありは質問候補から除き、全項目記載ありでも応募可・条件確定などの判定を出さない。

回答変更で結果・コピー通知を消し、再作成を促す。明示クリアで初期化。コピー用テキストは読取専用で表示し、API失敗時も手動コピーできる。コピー完了待ち中の編集・クリア後に旧通知を再表示しない。会社名を含まないため、複数求人を扱う場合の識別は本人の持ち帰り先で行う。
