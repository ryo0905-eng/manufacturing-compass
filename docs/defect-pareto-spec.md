# 不良の優先順位ボード

更新日：2026-09-23。実装上はindex可能・通常表示。本番反映・GA4受信は未確認。

## 目的と範囲

利用者の分類別件数を集計する実務ツール。既存の歩留まり原因調査が固定教材であることを確認し、別入口 `/tools/defect-pareto` として追加する。企画第二候補をユーザーの「どんどん作って」の継続指示で実装。需要の検証結果による追加と主張しない。第三候補は今回含めない。

## 入力・集計

分類と件数の2列をタブまたはカンマで貼り付け。正確な見出し「分類」「件数」は任意。空行・先頭BOMを除外し、前後空白を取り除く。CSVファイル、引用符エスケープ、複数行セルは非対応。カンマを含む分類名はタブ区切りを使う。

最大30入力行、分類1〜40 Unicodeコードポイント、入力12,000文字、件数0〜10億の整数。小数・指数・符号・非有限値・桁区切り・余分な列は拒否し、入力行番号を示す。分類に制御文字を許可しない。データを黙って切り捨てない。最大合計300億は安全な整数範囲内。

同名分類の完全一致（前後空白除去後）だけ合算候補とし、合計・行数を表示して明示確認する。キャンセルや入力変更で保留を破棄。件数降順、同率は初出順。構成比は件数／全件数、累積比率は並べた累積件数／全件数。比率表示のみ小数第1位へ丸める。ゼロ件分類も保持し、合計0では図の線を出さず、表の比率を算出不可とする。

## 図・出力

棒は件数、折れ線と点は累積比率。左軸の総件数と右軸の100%を整合させ、図には番号、下の表には分類名・値を表示する。図と表は小さい画面では内部スクロール。色だけでなく棒／線／点と凡例で区別する。

SVG生成は画面と保存で共通。保存版には全分類の凡例を付け、架空例を明記する。自由文字はXMLエスケープ。表コピーはタブ区切りで、数式に解釈され得る先頭文字の分類にアポストロフィを付加。Clipboard API失敗時は選択可能なテキストを表示する。コピー完了待ち中の編集で古い通知・テキストを戻さない。SVGは固定ファイル名・端末ダウンロード。保存要求を保存成功と扱わない。

入力編集・再計算・サンプル・クリアは旧結果・合算保留・コピー表示を破棄。入力の自動保存、URL埋め込み、外部送信はない。初期表示は空で、架空例は明示操作でのみ表示する。

## 正確性・公開

[ASQのパレート図手順](https://asq.org/quality-resources/pareto) を2026-09-23に確認。分類ごとの集計、降順、構成比、累積、左右軸の対応を反映。構成比と不良率・歩留まりを区別し、集計期間・重複計数・重大性・発生機会を別途確認する。原因や優先順位を自動判定しない。

canonical・WebApplication・BreadcrumbList・meta・sitemapを同時追加。一覧とツール案内、原因調査教材から入口を追加。結果から教材へのリンクはデータを引き継がない。
