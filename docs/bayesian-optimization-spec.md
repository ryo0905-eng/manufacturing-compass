# ベイズ最適化体験アプリ

最終更新日: 2026-09-21

## 目的・範囲

`/tools/bayesian-optimization` は、架空の成膜工程で「まず試す → 広く調べる → 予測で次を選ぶ → 確認 → 振り返り」を約5分で体験する日本語教材。実設備への条件推奨、原因の証明、量産適合性の判定を行わない。DOE既存ツールは効果・交互作用・ANOVA、このアプリは次の実験を選ぶ役割とする。

1シナリオ、2因子、膜厚むら1指標、12回に限定する。CSV、対戦、アカウント、入力保存、英語版、外部API、パラメータ調整UIは対象外。翻訳を見据えてUI文言をデータへ分離する。

## 実験・データの境界

- 温度300〜500℃（5℃刻み）、圧力20〜100Pa（2Pa刻み）。候補は41×41点。
- 膜厚むらは「面内膜厚の標準偏差÷平均膜厚×100」の教材上の指標。小さいほど良い。膜厚の個々の測定点は生成しない。
- 自由実験1回 → 四隅＋中央のDOE5回 → 本人が1回 → 本人またはBOで4回 → 確認1回。DOEは原子的に5観測を追加し、途中状態を作らない。
- 自由実験とDOEの重複は再測定として残す。BOは実験済み点を除外するが、手動での再測定は許可する。
- 履歴は温度・圧力・測定値・実験番号・選択方法のみ。真値・予測値を混入させない。
- simulatorは測定と終了後の答え合わせ、modelは観測からの推定・推奨、sessionは予算と状態遷移を担当。modelはtypesのみimportできる。
- ブラウザ配信されたソースを秘匿する設計ではない。学習中の表示と推定への真値流入を防ぐ。

## 応答関数と再現性

版 `deposition-v1`、初期シード `20260921`。

```text
u = (温度 − 400) / 100
v = (圧力 − 60) / 40
a = u − 0.35
b = v + 0.30
f = 2 + 1.5(b − 0.55a)² + 0.6(a + 0.2)² + 0.7{1 − cos(4a + b)}
y = f + ε, ε ~ Normal(0, 0.10²)
```

企画の初期式は中央点がほぼ最良となり、30シードの評価でBO・ランダムとも初期最良値から改善しなかった。このため谷を温度方向+0.35、圧力方向−0.30だけ移動した。交互作用・起伏・ノイズ・予測方式は維持。BOが答えを参照して調整する仕組みではなく、固定教材の設計変更である。

Mulberry32とBox–Muller法を使用。測定ノイズとDOE順序の状態を別の固定ソルトで初期化する。再描画、条件選択、表示切り替えは乱数を消費しない。同じ版・シード・操作順で再現し、再挑戦は同じシードへ戻す。DOE5点はFisher–Yatesでランダム化する。時間ドリフトはモデル化しない。

## ガウス過程と獲得関数

- 各軸を0〜1に正規化。Matérn 5/2、長さ尺度0.3、信号標準偏差1.5、既知ノイズ標準偏差0.10を固定する。
- 事前平均は初期6観測の平均を固定する。ハイパーパラメータ最適化は行わない。
- Cholesky分解と三角連立方程式で平均・潜在応答の分散を求める。対角jitterは1e-10。丸め程度の負分散のみ0に補正し、大きな負値・非有限値は失敗とする。
- LCB = 平均 − 2×潜在標準偏差。未実験候補の最小を推奨する。同値では圧力昇順・温度昇順を使用する。
- 確認実験は実験済みの予測平均最小点。確認前の予測を保持し、確認後の予測で過去の予測を書き換えない。
- 計算失敗時は観測を保持、予測と推奨を消去、追加実験を停止する。再挑戦で初期化できる。真値へのフォールバックはない。

不確かさ表示は「平均的な品質を絞り込めていない程度」。次回観測の分散は潜在分散＋ノイズ分散。固定カーネルでは不確かさは測定位置・回数に依存し、意外な測定値だから増えたとは説明しない。低い不確かさはモデルの正しさを保証しない。

## 表示・アクセシビリティ

Canvasの品質ヒートマップとSVGの軸・点を重ねる。品質予測と真値の尺度は0〜12%に固定し、範囲外の色は端に飽和させる。不確かさは0〜1.5ポイントの別尺度。選択条件の数値は飽和させない。

実験済み○、選択＋、推奨◇、DOE予定□。重複点は実験番号をまとめ、履歴で全測定を読めるようにする。マップ選択と同じ操作を、ラベル付き数値入力・標準スライダーで行える。入力範囲外・空欄では実験できない。実験結果をpolite live regionで通知。200ms以内の更新演出、reduced-motionでは演出なし。Canvasを利用できなくても数値入力・予測値・履歴で操作可能。

探索中の改善図は観測値の点と観測最小値の階段線。終了後に真値と真値の累積最小値へ切り替え、41×41格子の最良値を破線表示する。連続空間の最適解と呼ばない。DOEを探索経路線で結ばず、追加7〜11回目だけを結ぶ。12回目の確認対象について確認前予測・観測・真値を併記する。

DOEとBOは必須のセットではない、DOEは初期専用ではない、毎回最良条件に届かない、条件探索と原因解明は別、1回の確認で再現性を証明しないことを、段階説明と静的本文で伝える。

## 統合・計測

ツール一覧のDOE直後に入口を置き「実務利用：教育用」とする。DOE・成膜記事から導線を追加。終了後はDOE、工程比較、安定工程の能力評価へ案内し、観測データを転送しない。canonical、WebApplication、パンくず、sitemap、出典・確認日を付ける。操作とは別にServer Componentの概要・手順・用語・限界を初期HTMLへ含める。

`bo_started / bo_doe_completed / bo_experiment / bo_completed / bo_retried / bo_related_clicked` を既存Analyticsへ送る。プロパティは固定version、stage、method、destinationのみ。観測値、条件値、履歴、シード、自由入力は送らない。状態はメモリのみで、外部API・保存・個人情報を追加しない。

## 検証・残作業

`node tests/unit/bayesian-optimization.cjs` はGPを独立したGauss–Jordan参照計算と照合し、分散・重複・近接・同値・境界・有限性・再現・情報分離・予算・失敗を検証する。30シードで同じ初期6点・手動7点目・予算・ノイズ列を揃えてBOとランダムを比較する。双方に同じGPによる最終確認を付け、真の探索最良値と最終候補値を分けて報告する。

初回の移動後評価では、真の探索最良値の平均が初期2.760%、BO2.075%、ランダム2.599%。最終候補の真値平均はBO2.088%、ランダム2.621%。これは固定教材と特定30シードでの開発結果であり、一般的な性能比較ではない。この実行環境の更新中央値は約12ms、95パーセンタイル約14ms。スマホ性能とは区別する。

`node tests/unit/bayesian-optimization-ui.cjs` は操作フロー、初回の自由選択、表示切替での乱数不変、入力エラー、古いイベント・ダブルクリック、失敗時停止、リセット、真値公開、計測項目、SSRを検証する。DOMを実際に操作するブラウザ試験の代わりではない。

公開前の確認事項として、運営者を含む製造経験者3人の試用（誘導なしで完了・中央値約5分・予測と真値の区別・探索の理由・観測最良だけで決めない理解）、スマホ・キーボード・reduced-motionの実画面確認が残る。ブラウザ検証は依頼時のみ行う。スマホ更新100ms以内を目標とし、未達時に限りWorker化を検討する。これらを未実施のまま学習効果・操作品質の検証済みとは表現しない。
