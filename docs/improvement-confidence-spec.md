# 改善の差を見極める：サンプル数と信頼区間

最終更新日: 2026-09-22

## 目的と体験

`/tools/improvement-confidence` は若手製造技術者・統計の初学者向けの教育用教材。案内付き約5分の3ケースと、その後の自由実験で、平均差、不確かさ、実務上ほしい改善幅を分ける。実測データ入力・p値・必要サンプル数の算出・採用の自動判定は提供しない。

架空の膜厚工程の目標は100nm、変更前の真の平均は108nm。変更後はケース1から108／107／104nm。両条件の標準偏差3nm、ほしい改善幅2nm。薄いほど良いとは教えず、他の品質特性・安定性・安全性・費用の確認を残す。

初めはケース番号だけを表示。各ケースで各条件5→20→100個を見て行動を選び、振り返りで真値を開示する。途中で以前の測定数へ戻れるが、初めて20個を見る前に100個へ飛ばない。完成したケースの回答と真値は保持し、戻っても完了イベントを再送しない。3ケース完了後に自由実験へ進む。正誤の採点はしない。

自由実験は変化量0／1／4nm、標準偏差1／3／6nm、各条件5／20／100個、ほしい改善幅1／2／3nm。既定値1／3／20／2。設定だけでは既存結果を変更せず、実行時設定を結果へ併記する。20回の全履歴を保持し、上限時のみ全消去して再開する。消去後も実験番号を継続し、乱数列を再使用しない。良い結果が出るまでの測定や履歴の選別には通常の95%という説明をそのまま適用できないと伝える。

## 数値・状態設計

- 差は変更前−変更後。観測だけから平均、不偏分散、標準誤差、Welch–Satterthwaite自由度、両側95%信頼区間を求める。真の平均や設定値は解析・行動フィードバックへ渡さない。
- t分布上側2.5%点を正則化不完全ベータ関数と二分探索で求める。ツール内実装で、既存DOE計算は変更しない。ベータ連分数は500回、分位点探索は100回を上限とし、未収束は停止する。
- 独立正規分布の教材モデル。版 `improvement-confidence-v1`、シード20260922を含むFNV-1aとMulberry32の列をBox–Muller法へ渡す。条件・ケース・実験番号で分離し、0と1を除く乱数を使う。実工程の物理モデルではない。
- 案内付きは各100個を生成して先頭5／20／100個を使用。自由実験は実行ごとに別のサンプルを生成。再描画で引き直さず、結論に合わせたシード選別はしない。表示だけ小数2桁に丸める。
- 空・1件・非有限値・両群分散ゼロ・未収束をエラーにする。直前履歴を保持し、代替値を出さず、以後の操作を停止する。片群のみ分散ゼロは計算できる。
- 純粋な状態遷移とrevision、同期refで古いイベントハンドラーの連打を排除。計測はstate updater外で行う。

## UI・構成・公開

- Serverページで説明・出典・更新日・構造化データ、Client Componentで操作を提供。教材は `src/data/improvement-confidence.ts`、計算・生成・状態は `src/lib/improvement-confidence/`、UIは専用ディレクトリとCSS Module。
- 点と横線のSVG、差ゼロ・ほしい改善幅の基準線、同じ数値の表を併設する。測定値と数式はdetails。図の横軸は原則−12〜12nmで固定し、区間が収まらない場合だけ4nm刻みで拡張する。軸の説明を併記し、線の長さと数値・基準線を合わせて読む。
- 標準button・radio・select、44px以上の操作領域、focus-visible、段階移動後の作業領域フォーカス、スマホ縦配置を使用。アニメーションなし。
- ログイン・API・永続保存・CSV・英語版・新規依存は追加しない。既存一覧の訪問記録とは別に、回答・設定・測定値はメモリだけ。
- 数値・動作・出典・匿名化を検証してpublished・index可能にする。canonical、OG、WebApplication、パンくず、日付付きsitemapを同時に設定。ツール一覧の教育用表示と専用プレビュー、工程比較・相関と因果・DOEからの入口、完了後の3ツールへのリンクを追加。

## 計測と評価

`improvement_started`、`improvement_case_completed`、`improvement_guided_completed`、`improvement_experiment_run`、`improvement_related_clicked`。属性はversion・mode・case_id・destinationの固定分類のみ。観測値・設定値・行動選択は送信しない。

公開後は開始→3ケース完了→自由実験→関連遷移を確認し、検索需要・学習効果を評価する。本番反映と検索登録は実装完了から分ける。試用では「測定数で真の平均差は変わらない」「観測した平均差は揺れる」「不確かさと実務上の価値は別」を説明できるかを確認する。
