# 日本の半導体企業・拠点マップ データパイロット

最終更新日: 2026-09-03

## 役割

[`semiconductor-location-map-spec.md`](./semiconductor-location-map-spec.md) の公開判断に使う調査台帳です。

この文書にある拠点候補は未確認の調査対象であり、公開情報ではありません。正式な拠点名、所在地、稼働状態、半導体との関係、職種、採用状態は企業公式情報で確認してから公開データへ移します。

## パイロットで確認すること

- 会社と国内法人・製造子会社のどちらを `companyId` とするか
- 同じ敷地の本社、工場、研究所を一拠点として扱うか
- 稼働中、建設中、計画中を区別できるか
- 公式情報から拠点固有の製品・技術を確認できるか
- 会社全体の職種と拠点固有の職種を分離できるか
- 公式求人を拠点単位で確認できるか
- 住所を公開できない時に市区町村単位の座標へ落とせるか
- 1拠点の初回調査と再確認に必要な時間

### データ設計へ反映したこと

- 親企業の `companyId` と、運営法人の `legalEntityName` を分ける
- 同一敷地内の複数法人・機能をまとめられる `campusId` を持てるようにする
- 稼働中、建設中、計画中、確認不能を `operationalStatus` で区別する
- 公式拠点一覧に存在しても、半導体との関係と拠点機能が未確認なら公開しない
- 会社全体の採用職種を、根拠なく各拠点へ複製しない

## 1拠点ごとの調査項目

| 項目 | 必須 | 記録ルール |
| --- | --- | --- |
| 企業ID | 必須 | 既存企業と一致させる。国内法人を分ける必要がある場合は保留理由を記録する |
| 正式な拠点名 | 必須 | 企業公式の表記を使う |
| 都道府県・市区町村 | 必須 | 公式住所または公式アクセス情報で確認する |
| 住所 | 任意 | 企業が公開している範囲を超えて補完しない |
| 座標・精度 | 必須 | 住所、市区町村、都道府県のどの粒度かを記録する |
| 拠点種別 | 必須 | 公式の説明に基づき複数選択可とする |
| 半導体との関係 | 必須 | 製品、工程、装置、材料など公式に確認できる内容だけを書く |
| 主な製品・技術 | 任意 | 拠点固有と確認できない場合は会社全体の情報を流用しない |
| 共通職種分類 | 任意 | 拠点固有の根拠がある場合だけ設定する |
| 公式の職種名 | 任意 | 求人または拠点別採用情報の原文を保持する |
| 拠点情報の出典 | 必須 | URL、発行元、確認日、支える項目を記録する |
| 採用確認状態 | 必須 | 拠点の存在と分けて記録する |
| 採用情報の出典 | 条件付き必須 | 募集中と表示する場合は公式求人URLを必須とする |
| 稼働状態 | 必須 | 稼働中、建設中、計画中、確認不能を区別する |
| 次回確認日 | 必須 | 情報の種類に応じて設定する |

## 調査時間

各拠点について次を分けて記録します。

- 拠点の存在・所在地確認
- 半導体との関係・拠点種別確認
- 職種・採用状態確認
- データ入力とレビュー

初回10拠点の中央値を、50〜70拠点へ拡張した場合の運用工数見積もりに使います。

## 完了条件

- 10社を調査している
- 20拠点以上が公開基準を満たす、または満たせない理由を記録している
- 全拠点に出典、確認日、次回確認日がある
- 募集中と表示する全項目に有効な公式求人URLがある
- 会社全体の職種を拠点固有情報として誤表示していない
- 稼働中と計画中を区別している
- 初回調査時間の中央値を記録している
- 公開MVPへ進むか、対象またはデータ型を修正するか判断している

### 企画判断

1. 全国の「日本の半導体工場マップ／一覧」は小さいながら実需要が確認できたため、データパイロットを継続する。
2. 最初のSEO対象は `/semiconductor-map` の全国ハブとし、地図だけでなく初期HTMLに工場・研究開発・設計拠点の一覧と解説を持たせる。
3. 都道府県ページを4〜6件同時に作らない。最初はデータを十分にそろえられる場合の熊本を第一候補とし、最大1〜2件から始める。
4. 大阪、三重、広島、北海道はパイロットのデータ網羅性を確認する地域であり、現時点ではindexページの公開を前提にしない。
5. `/companies` は地域系需要より大きな改善余地がある。企業・拠点データの整備を同ページの検索意図、タイトル・説明、カテゴリ導線、企業詳細の品質改善にも再利用する。
6. マップ実装を先行させず、10社・20拠点の調査品質と更新工数を確認してから公開可否を判断する。
