# 日本の半導体企業・拠点マップ UI / UX仕様

最終更新日: 2026-09-04

## 状態

公開V0と、正確な拠点ピンを追加するV1の画面・操作仕様です。実装はまだ行っていません。

既存の企業一覧にある検索・分類UIと、半導体業界地図にある「地図／一覧」の切り替え方を土台にします。ただし、企業一覧の会社単位検索と、拠点マップの勤務地単位検索は同じ画面へ統合しません。

## 体験の中心

ユーザーが最初に答えたいのは「通える地域に、どのような仕事につながる拠点があるか」です。

```text
地域または職種を一つ選ぶ
  → 該当する拠点を一覧で比較する
  → 都道府県選択図で地域を切り替える
  → 拠点の役割と確認日を読む
  → 企業詳細または公式採用情報へ進む
```

V0では正確な位置関係を示さず、都道府県を選ぶ操作と拠点一覧に集中します。V1で確認済み座標の拠点だけ詳細地図へ追加します。

## ページ構成

全国ページ `/semiconductor-map` は次の順にします。

1. コンパクトな見出し、ページの役割、最終更新日
2. 「地域から」「職種から」「拠点種別から」の短い入口
3. キーワード検索、主要フィルター、該当件数
4. 一覧／都道府県選択図の切り替え
5. 拠点結果
6. 掲載基準、求人表示の読み方、情報源
7. 業界地図、企業一覧、Career Compassへの関連導線

検索・操作領域をページ上部へ置きます。長いSEO説明を操作領域より前へ置きません。一方、初期HTMLには見出し、短い説明、公開拠点一覧を含めます。

## モバイル

### 初期状態

- 一覧を初期表示する
- V0では地図ライブラリとタイルを読み込まない
- 検索欄の直下に、選択中条件と件数を表示する
- 主要フィルターは「都道府県」「拠点種別」「職種」の3つにする
- 業界分類と工程は「条件を追加」に収納する
- 条件未選択時は、公開基準を満たす全拠点を都道府県順で表示する

### 操作領域

画面上に常時並べる操作を増やしすぎません。

- キーワード検索
- `条件を絞る` ボタン
- `一覧` / `地域から選ぶ` の表示切り替え
- 適用中の条件チップ
- `すべて解除`

フィルターは画面下から開くダイアログとして設計します。開いた状態では背景を操作不可にし、見出し、閉じるボタン、適用ボタンへフォーカスを移動できるようにします。

### 都道府県選択図

- 北海道、東北、関東、中部、近畿、中国、四国、九州・沖縄の地域ブロックごとに都道府県ボタンを配置する
- 公開拠点がある都道府県だけ件数を表示し、0件の都道府県は選択不可にする
- 選択すると同じ画面の一覧を絞り込み、選択中の都道府県名と件数を表示する
- 正確な地理形状や施設位置を示す図ではないことを短く明記する
- 選択図を閉じても、適用した都道府県条件を維持する

スマートフォンでは選択図へ検索欄、複数フィルター、長い説明を重ねません。

## デスクトップ

- 操作領域の下を、都道府県選択図40%、拠点一覧60%程度の2カラムにする
- 一覧側だけをスクロールさせず、ページ全体の自然なスクロールを優先する
- 都道府県を選ぶと、該当する一覧だけを表示する
- 選択状態は色だけでなく、枠、ラベル、`選択中` のテキストでも示す

選択図の高さを画面いっぱいにせず、ページの説明、掲載基準、関連導線へ自然にスクロールできるようにします。

## 最初の入口

初回ユーザー向けに、データから生成する4〜6個の短い入口を表示します。

- 熊本の拠点を見る
- 工場から探す
- 研究開発・設計拠点を見る
- 生産・プロセスの仕事から探す
- 設備・施設の仕事から探す
- 品質・信頼性の仕事から探す

入口の件数が0件になるものは表示しません。人気順を装わず、掲載データの代表的な探し方として提示します。

## 検索とフィルター

### キーワード検索

検索対象は次に限定します。

- 企業名、日本語企業名
- 拠点名
- 都道府県、市区町村
- 確認済みの製品・技術
- 共通職種分類と、根拠のある原文職種名

自由入力の検索語は計測イベントへ送信しません。検索を使った事実だけを計測します。

### 主要フィルター

| フィルター | 初期選択肢 | 補足 |
| --- | --- | --- |
| 都道府県 | 公開拠点がある都道府県だけ | 0件の都道府県を並べない |
| 拠点種別 | 工場、研究開発、設計、本社・事業所、フィールドサービス | 複数の役割を持つ拠点は複数該当できる |
| 職種 | 生産・プロセス、設備・施設、品質、装置開発、設計・ソフト、FAE・フィールド | 拠点との根拠がある職種だけに該当させる |

### 追加フィルター

- IDM、ファウンドリ、製造装置、材料、ファブレスなどの業界分類
- 稼働中、建設中、計画中
- 公式求人確認済み

`公式求人確認済み` は期限内の `official-opening-confirmed` だけを対象にします。「中途採用あり」という恒久属性にはしません。

### URL状態

共有に必要な条件だけURLへ反映します。

```text
/semiconductor-map?prefecture=43&type=factory&job=quality-reliability
```

- キーと値は有限の許可リストから生成する
- V0の `view=regions` は共有できるがcanonicalへ含めない
- 自由入力検索はURLへ残しても、計測へ送信しない
- パラメータ付きページをindex対象にしない
- V0では都道府県の固定ページを作らない
- V1以降、公開基準を満たす地域だけ `/semiconductor-map/kumamoto` のような固定ページを検討する

## 拠点結果

同じ敷地に複数法人や施設がある場合も、物理拠点の表示は一件にします。

### 一覧の先頭情報

1. 企業名
2. 正式な拠点名
3. 都道府県・市区町村
4. 拠点種別
5. 拠点で確認できる役割・技術
6. 根拠のある職種分類

### 補足情報

- 稼働中、建設中、計画中などの状態
- 発表済みの生産終了、閉鎖、移転
- 採用情報の確認状態と確認日
- 拠点情報の最終確認日

### 操作

- `企業詳細を見る`
- `公式の拠点情報を見る`
- 期限内の情報がある場合だけ `公式採用情報を見る`

広告リンクは拠点結果へ混ぜません。Career Compassや転職相談への導線は、複数拠点を比較した後の独立したセクションに置きます。

## V0の都道府県選択図

- 外部地図データ、背景タイル、拠点座標を使用しない
- 地域ブロックと都道府県名の配置で、日本全国から選べることを伝える
- 都道府県ごとの公開拠点数を表示する
- 拠点種別、稼働状態、求人状態を選択図上の色へ重ねない
- 選択図は一覧を絞り込む操作であり、施設位置や距離を表さないと明記する

## V1の詳細地図

- 物理拠点一件につき一つのピンを使う
- 工場、研究開発、設計などの違いは、色だけでなくアイコンまたは短い文字ラベルでも示す
- 同じ拠点に複数種別がある場合、最も重要な一種類へ勝手に丸めず、選択後の詳細にすべて表示する
- 稼働状態と求人状態を同じ色・アイコンで表現しない
- 建設中・計画中は現在働ける拠点と誤解されないラベルを付ける
- 座標未確認の拠点は一覧へ掲載できても、地図へ暫定ピンを表示しない

V0の利用結果から詳細地図の需要を確認してから実装します。全国表示で重なりが問題になるまでは、クラスタリング用の追加ライブラリを入れません。

## 状態別表示

### 0件

- `条件に一致する拠点はありません` と明記する
- 条件を一つずつ外せるようにする
- 近隣県を自動推薦せず、地域条件の解除を提案する

### 座標未確認

- V0では座標確認状態を利用者へ表示しない
- V1の詳細地図へ都道府県代表点などの代替ピンを置かない
- 住所と公式情報へのリンクは、公開基準を満たす場合だけ表示する

### 求人情報の期限切れ

- `現在募集中` と表示しない
- `公式採用ページあり・最終確認日` へ戻す
- 求人フィルターの対象から外す

### 将来変更が発表済み

- 現在状態を先に表示する
- 発表済み変更は対象施設、公式表現、確認日を分けて表示する
- 日付が未確定なら推定日を作らない

## アクセシビリティ

- 都道府県選択図の前に `拠点一覧へ移動` リンクを置く
- 件数変更は `aria-live="polite"` で通知する
- 都道府県ボタンには都道府県名と公開拠点数を含む操作名を付ける
- 選択図を使わず、キーボードだけで検索、絞り込み、拠点詳細へ到達できるようにする
- タップ領域は44px程度を下回らない
- フォーカス表示を消さない
- 地理的な配置や色の識別だけを必須操作にしない
- 都道府県選択図と一覧の選択状態を読み上げ可能にする

## 計測

既存仕様のイベントを次の場面に限定して送ります。

| イベント | タイミング | 値 |
| --- | --- | --- |
| `location_map_prefecture_select` | 都道府県を適用 | 都道府県コード |
| `location_map_filter_use` | 拠点種別、職種などを適用 | 有限の分類ID |
| `location_map_location_open` | 拠点詳細を開く | 拠点ID |
| `location_map_company_click` | 企業詳細へ進む | 企業ID、拠点ID |
| `location_map_official_career_click` | 公式採用情報へ進む | 企業ID、拠点ID |
| `location_map_career_compass_click` | Career Compassへ進む | 導線位置 |

V1でも地図のパンやズームを細かく送信しません。自由入力検索、詳細な希望勤務地、住所、位置情報を送信しません。

## 既存UIから再利用する考え方

- `FilterableCompanies`: 検索、選択条件、0件表示、有限値だけを送る計測
- `IndustryMapExplorer`: 表示切り替え、選択状態の同期、Escapeで詳細を閉じる操作
- デザインシステム: 中立色、1px罫線、影なし、探索画面の密度、モバイル優先

コンポーネント自体をそのまま流用するとは限りません。会社単位と拠点単位の状態を混ぜないため、データ型と表示責務は分けます。

## 実装前の受け入れ条件

- モバイルの初期表示で、選択図を開かずに検索、絞り込み、拠点詳細へ進める
- PCで一覧と都道府県選択図の状態が同期する
- 都道府県選択図を無効にしても公開拠点情報と内部リンクを読める
- 求人期限切れと建設中を誤解なく表示できる
- 主要フィルターを3種類に保てる
- 0件から条件を解除して探索を再開できる
- キーボードだけで同じ情報へ到達できる
- V0で座標と第三者地図データを読み込まない
