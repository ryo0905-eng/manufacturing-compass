# 半導体職種マップ：公開後の運用検証

最終更新日: 2026-09-17
状態: 5人の個別試用は実施しない。公開β版の利用状況・問い合わせ・根拠レビューで改善する。

## 検証する仮説

[対応表と結果カード](./role-map-pilot.md)を使うと、半導体の仕事を探している製造業経験者が、知らなかった職種名・検索語から経験と接点のある求人を探しやすくなる。

参加者を集める個別試用は運用負担が高いため、2026-09-17の運営者判断でスキップする。未実施の試用結果を推測で補わず、公開β版 `/roles` の匿名操作イベント、Search Console、任意の問い合わせ、公式資料のレビューを使う。

## 収集する情報

| 情報 | 確認すること | 収集しないもの |
| --- | --- | --- |
| `role_map_start` | 業務選択が始まった回数 | 選択した業務、職種、個人情報 |
| `role_map_result_view` | 候補表示まで進んだ回数 | 候補名、順位、内部スコア |
| `role_map_search_copy` | 検索語を持ち帰った回数 | コピーした検索語、クリップボード内容 |
| `role_map_related_click` | 関連情報・問い合わせへ進んだ回数 | 遷移先の候補職務、回答内容 |
| Search Console | 職種名・比較・仕事内容に関する検索流入 | 個人を特定する検索履歴 |
| 問い合わせ | 候補の違和感、説明不足、扱ってほしい仕事 | 勤務先の機密情報、職務経歴書、個人用求人URL |

回答内容はURL、Cookie、localStorage、Analyticsへ送らない。問い合わせは任意とし、公開画面から既存の問い合わせページへ案内する。

## 確認周期

- 公開直後に4イベントの本番受信を確認する。
- 最初の4週間は週1回、その後は月1回、開始・結果・コピー・関連遷移の変化を見る。
- 月1回、リンク切れと問い合わせを確認する。
- 四半期ごとに、各Profileの中心業務・名称・根拠を公式資料と照合する。
- 職務群を追加する前に、その職務群の根拠ゲートを個別に確認する。

アクセスが少ない期間は比率だけで結論を出さない。イベント数を人数、コピーを求人発見と読み替えない。Search Consoleの流入増加だけで候補精度が確認できたとは扱わない。

## 継続・修正・停止の判断

### 継続

- 結果表示と検索語コピーが発生し、重大な誤認報告がない。
- 表示した共通業務と根拠資料の対応を説明できる。
- 更新担当と四半期レビューの時間を確保できる。

### 修正

- 結果表示はあるがコピーされない状態が続く。
- 「適性」「採用確率」「正式な職種認定」と受け取られる。
- 名称は合っていても、求人票で確認する担当範囲が不足している。
- 問い合わせや検索クエリで、同じ未対応職務の要望が繰り返される。

### 停止・非表示

- 中心業務を複数企業の公式情報で支えられない。
- 根拠資料と結果カードに重大な不一致がある。
- 条件の違う企業例を合成しなければ候補を説明できない。
- 更新・問い合わせ対応を継続できない。

イベントは利用の代理指標であり、求人発見や転職成功の証明ではない。数値だけで職務群を増やさず、問い合わせと根拠の両方を確認する。

## 8職務群へ拡張する条件

5人試用は条件にしない。次を満たした職務群から追加する。

1. 運営者が既存4Profileの対応付けをレビューし、誤読を修正している。
2. 追加Profileについて、独立した2社以上・計3資料以上があり、中心業務を2社以上で確認できる。
3. 表示名称、共通業務、会社による担当差、検索語、求人票の確認事項を説明できる。
4. 本番の固定イベントが受信でき、回答内容を送っていないことを確認している。
5. 月次・四半期レビューを継続できる。
